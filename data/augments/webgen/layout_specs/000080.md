# Layout spec

## Screen: home-all
- Viewport background is lavender. A bordered card sits at viewport top-center, occupying roughly the middle column horizontally and extending from near the top toward the bottom.
- Header (card-top): single title "To-Do List" centered at card-top-center, rendered as a large indigo heading. No other header elements.
- Main content (card body, stacked top to bottom):
  - Add-task row (card-top, below title): a wide text input with placeholder "What needs to be done?" occupies the row-left and stretches across most of the row; an "Add" button with solid indigo fill and white label sits at row-right.
  - Search row (below add-task row): a single full-width text input with placeholder "Search tasks..." spans the row.
  - Filter row (below search): three pill-shaped buttons in a horizontal row, aligned to row-left, in order: "All" (selected — solid indigo fill, white label), "Active" (outlined indigo), "Completed" (outlined indigo).
  - Task list (middle of card, below filters): vertically stacked task rows, each row is a bordered rectangle spanning the card width.
    - First task row: checkbox (unchecked) at row-left, task label "Buy groceries" immediately to the right of the checkbox, then a gap, then two outlined indigo buttons "Edit" and "Delete" grouped at row-right.
    - Second task row: checkbox (checked, indigo fill with white check) at row-left, task label "Read a book" rendered with strikethrough and muted color, then "Edit" and "Delete" outlined indigo buttons at row-right.
  - Footer row (below task list, inside card): text "1 item left" at row-left (indigo link-style text); outlined indigo button "Clear completed" at row-right.
- Interactive elements: "Add" (primary), "All"/"Active"/"Completed" filter toggles, per-row checkbox, per-row "Edit" and "Delete" buttons, "Clear completed" button.

## Screen: edit-mode
- Viewport background lavender; same bordered card at viewport top-center as in home-all.
- Header (card-top): title "To-Do List" centered at card-top-center.
- Main content (stacked top to bottom):
  - Add-task row (card-top): "What needs to be done?" input at row-left stretching wide; solid indigo "Add" button at row-right.
  - Search row: full-width "Search tasks..." input.
  - Filter row: "All" (selected, solid indigo), "Active" (outlined), "Completed" (outlined), aligned row-left.
  - Task list:
    - First task row is in edit mode: a text input pre-filled with "Buy groceries" occupies row-left and most of the row width; immediately to its right a solid indigo "Save" button with white label, then an outlined indigo "Cancel" button — Save and Cancel sit at row-right. No checkbox or Edit/Delete buttons in this row while editing.
    - Second task row: checkbox (checked, indigo) at row-left, "Read a book" with strikethrough, outlined "Edit" and "Delete" buttons at row-right.
  - Footer row: "1 item left" at row-left; outlined "Clear completed" button at row-right.
- Forms: edit input (text) → Save (primary) / Cancel (secondary).
