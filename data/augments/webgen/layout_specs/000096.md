# Layout spec

## Screen: home
- Header: top of viewport, full width — "Wanderly Travel" wordmark at header-left; at header-right a horizontal row of nav buttons in order "Home" (highlighted as current), "Trains", "Flights", "Hotels", "My Orders", followed by the text "Hi, admin", then a "Logout" button at the far header-right.
- Main content: a single wide card region at top-center of the page below the header.
  - Card-top: title "Plan Your Journey" left-aligned, with a thin horizontal divider directly beneath it.
  - Below the divider (card-upper-middle): subtitle text "Book trains, flights, and hotels — all in one place." left-aligned.
  - Card-bottom: a horizontal row of four equal-width tiles spanning the card. Each tile has a centered icon glyph at tile-top and a bold label at tile-center-bottom. Left-to-right order: "Train Tickets", "Air Tickets" (visible airplane icon), "Hotels", "My Orders".
- Interactive elements: header nav buttons (Home/Trains/Flights/Hotels/My Orders), "Logout" (top-right), four tile buttons in the main card.
- Empty space below the card fills the remainder of the viewport.

  - Card-middle: a single row of four controls, left-to-right — labeled dropdown "From" (`-- select --`), labeled dropdown "To" (`-- select --`), labeled date input "Date" (mm/dd/yyyy), and a "Search" button at card-middle-right.
