# Layout spec

## Screen: home
- Header: top of viewport, full-width — circular "A" avatar then wordmark "The All-In Bourbon Bar" at header-left; nav row at header-right with buttons in order: Home (highlighted/active), Menu, Poker Room, Events, Reservations, Cart, italic text "Hi, admin", Logout.
- Main content: page-center column.
  - Hero card (top, full-width of content area, outlined): heading "Welcome to The All-In Bourbon Bar" at card-top-center; tagline "Rare bourbons. High stakes. Unforgettable nights." centered below; two buttons in a row at card-bottom-center: primary "View Menu" (filled) and secondary "Make a Reservation" (outlined).
  - Three-column feature row below hero, each column a left-bar-accented block: first column "Curated Menu" with paragraph about 200 bourbons; second column "Private Poker Room" with members-only blurb; third column "Events & Promotions" with tastings blurb.
- Footer: bottom of viewport, full-width centered text "© The All-In Bourbon Bar · 21+ Only".

## Screen: logout
- Header: same as home but rightmost nav slot shows "Login" instead of "Hi, admin" + "Logout".
- Main content: identical hero card and three-column feature row as home screen.
- Footer: same site footer.

Each item card: item name at card-top-left, price at card-top-right; one-line description below; "Add to Cart" filled button at card-bottom-left. Items shown: row 1 — Pappy Van Winkle 15yr $95, Buffalo Trace Single Barrel $18, Eagle Rare 10yr $22; row 2 — Four Roses Small Batch $16 (only one card on row 2).
