# Layout spec

## Screen: login
- Header: top of viewport — "Culinary Guide" wordmark at header-left; nav buttons at header-right in a row: "Restaurants", "Recipes", "Login" (Login appears as the emphasized/active button).
- Horizontal divider spans full width below the header.
- Main content: a bordered card anchored at middle-left of the page (upper-left area below header).
  - Card-top: heading "Login".
  - Below heading, stacked form fields:
    - Label "Username or Email" → single-line text input.
    - Label "Password" → single-line text input.
  - Primary CTA "Sign in" as a full-width filled button below the inputs.
  - Card-bottom: small helper text "Demo: admin / admin123456".
- Footer: bottom of viewport — horizontal divider, then footer-center text "Culinary Guide · lemon chiffon & chocolate".

  - Card-top: heading "Login".
  - Label "Username or Email" → text input pre-filled with "wrong".
