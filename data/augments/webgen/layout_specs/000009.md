# Layout spec

## Screen: history-empty
- Header: top of viewport spanning full width — knight icon and wordmark "Chess Online" at header-left; four nav buttons in a row at header-right in order: "Play", "Games", "History" (visually highlighted/active), "Stats". A horizontal divider line sits directly below the header.
- Main content: single bordered panel occupying top-center of the viewport below the divider, taking most of the width with margins on both sides.
  - Panel-top: heading "Current Game History".
  - Below heading: paragraph text "No moves recorded yet in the current game."
  - Panel-middle: heading "All Games".
  - Below heading: paragraph text "No games played yet."
- Interactive elements: nav buttons "Play", "Games", "History", "Stats" at header-right.
- Empty state: "No moves recorded yet in the current game." under the first heading; "No games played yet." under the second heading.

## Screen: history-with-game
- Header: same as history-empty; "History" nav button highlighted at header-right.
- Main content: bordered panel top-center below the divider.
  - Panel-top: heading "Current Game History".
  - Below heading: paragraph text "No moves recorded yet in the current game."
  - Panel-middle: heading "All Games".
  - Below the "All Games" heading: a single bordered list-row card spanning nearly the full panel width. Card-left contains bold text "Game #1" on the first line, and subtext "active · medium" on the second line.
- Interactive elements: nav buttons at header-right; the game row itself has no visible action button.

## Screen: lobby-empty
- Header: same wordmark at header-left; nav buttons "Play", "Games" (highlighted/active), "History", "Stats" at header-right. Divider below.
- Main content: bordered panel top-center below the divider.
  - Panel-top: heading "Games Lobby".
  - Below heading: primary filled button "Create New Game" at panel-left.
  - Below button: paragraph text "No games yet."
- Interactive elements: "Create New Game" button (primary/filled), header nav buttons.
- Empty state: "No games yet." at panel-middle-left.

## Screen: lobby-with-game
- Header: same as lobby-empty with "Games" nav highlighted.
- Main content: bordered panel top-center below the divider.
  - Panel-top: heading "Games Lobby".
  - Below heading: primary filled button "Create New Game" at panel-left.
  - Below the button: a single bordered list-row card spanning nearly the full panel width.
    - Card-left: bold "Game #1" on the first line, subtext "status: active · difficulty: medium · theme: classic" on the second line.
    - Card-right: filled secondary button "Join".
- Interactive elements: "Create New Game" button, "Join" button on the game row, header nav buttons.

## Screen: play-initial
- Header: wordmark at header-left; nav buttons "Play" (highlighted/active), "Games", "History", "Stats" at header-right. Divider below.
- Main content: two-column layout below the divider.
  - Left column (middle-left of viewport): a large square chess board with a thick outlined border showing an 8x8 grid, alternating light-tan and brown squares (classic theme), pieces set to standard chess starting position — black pieces on the top two rows, white pieces on the bottom two rows. Directly under the board, center-aligned: a pill-shaped status banner reading "Start a new game to play."
  - Right column (middle-right of viewport): a vertical stack of four bordered panels of equal width:
    1. First panel top-right: heading "Controls" at panel-top, followed by a horizontal row of three buttons: "New Game" (filled/enabled), "Undo" (disabled/muted), "Resign" (disabled/muted).
    2. Second panel: heading "Board Theme" at panel-top, followed by a wrapping row of four theme buttons: "classic" (filled/selected), "ocean", "emerald", "rose".
    3. Third panel: heading "Difficulty" at panel-top, followed by a row of three buttons: "easy", "medium" (filled/selected), "hard".
    4. Fourth panel: heading "Move Log" at panel-top, followed by text "No moves yet."
- Interactive elements: header nav; "New Game", "Undo", "Resign"; theme buttons "classic/ocean/emerald/rose"; difficulty buttons "easy/medium/hard".

## Screen: play-new-game
- Header: same as play-initial with "Play" highlighted.
- Main content: same two-column layout as play-initial.
  - Left column: same board (classic theme, starting position). Status banner beneath the board reads "Game started. You play white."
  - Right column, top panel "Controls": buttons row shows "New Game" (filled), "Undo" (disabled/muted), "Resign" (filled/enabled).
  - Other right-column panels identical to play-initial: "Board Theme" with "classic" selected; "Difficulty" with "medium" selected; "Move Log" showing "No moves yet."
- Interactive elements: all header nav; controls "New Game" and "Resign" active, "Undo" disabled; theme and difficulty buttons.

## Screen: play-difficulty-hard
- Header: same as play-initial with "Play" highlighted.
- Main content: same two-column layout.
  - Left column: board (classic theme, starting position). Status banner beneath reads "Game started. You play white."
  - Right column, "Controls" panel: "New Game", "Undo" (disabled), "Resign" (enabled).
  - "Board Theme" panel: "classic" selected among "classic/ocean/emerald/rose".
  - "Difficulty" panel: "hard" is the selected/filled button among "easy/medium/hard".
  - "Move Log" panel: "No moves yet."

## Screen: play-theme-ocean
- Header: same with "Play" highlighted.
- Main content: same two-column layout.
  - Left column: board rendered with the ocean theme — alternating light-gray/off-white and steel-blue/gray squares in place of the tan/brown scheme. Standard starting position. Status banner beneath reads "Game started. You play white."
  - Right column, "Controls" panel: "New Game", "Undo" (disabled), "Resign" (enabled).
  - "Board Theme" panel: "ocean" is the selected/filled button; "classic", "emerald", "rose" are unselected outlined buttons.
  - "Difficulty" panel: "medium" selected.
  - "Move Log" panel: "No moves yet."

## Screen: play-resigned
- Header: same with "Play" highlighted.
- Main content: same two-column layout.
  - Left column: board (classic theme, starting position still shown). Status banner beneath center-aligned reads "You resigned."
  - Right column, "Controls" panel: "New Game" (enabled), "Undo" (disabled/muted), "Resign" (disabled/muted).
  - "Board Theme" panel: "classic" selected.
  - "Difficulty" panel: "medium" selected.
  - "Move Log" panel: "No moves yet."

## Screen: stats
- Header: wordmark at header-left; nav buttons "Play", "Games", "History", "Stats" (highlighted/active) at header-right. Divider below.
- Main content: bordered panel top-center below the divider.
  - Panel-top: heading "Statistics".
  - Below heading: a single horizontal row of five equally sized bordered stat cards spanning the panel width. Each card centers its content vertically with a large numeric value on top and a bold label beneath, in left-to-right order:
    1. "0" over "Wins"
    2. "0" over "Losses"
    3. "0" over "Draws"
    4. "0" over "Resigns"
    5. "0" over "Total Games"
- Interactive elements: header nav buttons only.
