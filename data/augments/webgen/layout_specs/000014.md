# Layout spec

## Screen: home
- Header: top of viewport, full width — at header-left a star glyph followed by the wordmark "Restore Credit Co."; at header-right a horizontal nav row with links "Home", "Services", "Credit Score", "Get Started". "Home" appears as the active nav item (filled pill background).
- Main content: directly below the header, centered column on the page.
  - Top region (hero, page-top, center-aligned): two-line headline "Repair Your Credit. Reclaim Your Future."; below it a paragraph of supporting copy ("Our experienced team helps you dispute inaccuracies, build positive credit history, and raise your score — so you can qualify for the loans, homes, and rates you deserve."); below that a primary CTA button labeled "Get a Free Consultation" centered horizontally.
  - Middle region (stats strip, just below hero, center-aligned): three stat items in a single horizontal row: "94 pts / Avg. score increase" at strip-left, "12,000+ / Clients helped" at strip-center, "A+ / BBB rating" at strip-right.
  - Lower region (services section, page-middle-to-bottom, center-aligned): section title "Our Credit Repair Services" at top-center, supporting line "Every plan is customized to your credit profile. Here is how we help." beneath it.
  - Service cards grid: 3 columns × 2 rows of bordered cards. First row, left→right: "Credit Report Analysis", "Dispute & Removal", "Debt Validation". Second row, left→right: "Credit Building", "Score Monitoring", "Financial Coaching". Each card has the title at card-top and a paragraph of body copy below it.
- Footer: bottom of viewport, full width — at footer-left "© 2026 Restore Credit Co. All rights reserved."; at footer-right phone "1-800-555-0142" and email "hello@restorecredit.example" in a row.

## Screen: services
- Header: same as home; "Services" nav item is the active (filled pill) item at header-right.
- Main content: centered column.
  - Top region (page-top, center-aligned): title "Our Credit Repair Services"; below it supporting line "Every plan is customized to your credit profile. Here is how we help."
  - Middle region (cards grid, page-middle): 3 columns × 2 rows of bordered cards. First row: "Credit Report Analysis", "Dispute & Removal", "Debt Validation". Second row: "Credit Building", "Score Monitoring", "Financial Coaching". Each card title at card-top with a paragraph beneath.
- Footer: same as home (copyright at footer-left, phone + email at footer-right).

## Screen: credit-score
- Header: same as home; "Credit Score" nav item is the active (filled pill) item at header-right.
- Main content: centered column below the header.
  - Top region (page-top, center-aligned): title "Free Credit Score Inquiry"; below it supporting line "Get a quick estimate of where your credit stands. Results are informational — a full audit gives the most accurate picture."
  - Middle region (two-column layout, page-middle): two bordered panels side by side, equal width.
    - Left panel (form): vertical stack of fields, each label above its input —
      - "Full Name" → text input
      - "Last 4 of SSN" → text input (placeholder "0000")
      - "Payment History" → select dropdown (visible option "Good — 1 or 2 late, long ago")
      - "Credit Utilization (%)" → numeric text input
      - "Open Accounts" → numeric text input
      - "Derogatory Marks" → numeric text input
      - "Credit Age (years)" → numeric text input
      - Bottom row of buttons (panel-bottom-left): primary button "Check My Score" then secondary outlined button "Reset".
    - Right panel (result placeholder, center-aligned within panel): heading-style text "Your estimated score will appear here" at vertical center; below it a line "Complete the form on the left to view your estimate."
- Footer: same as home.

- Footer: same as home.

## Screen: get-started
- Header: same as home; "Get Started" nav item is the active (filled pill) item at header-right.
- Main content: centered column.
  - Top region (page-top, center-aligned): title "Get Your Free Consultation"; below it supporting line "Tell us about yourself and your credit situation. There's no obligation, and your information stays private."
  - Middle region (single bordered form container, page-middle): contains two stacked grouped fieldsets, each with a titled border.
    - First fieldset titled "Personal Information" (title at fieldset-top-left):
      - Row 1: "First Name *" (left half) → text input ; "Last Name *" (right half) → text input.
      - Row 2: "Email *" (left half) → text input ; "Phone *" (right half) → text input (placeholder "(555) 555-1212").
      - Row 3 (full width): "Street Address *" → text input.
      - Row 4: "City *" (left third) → text input ; "State *" (middle third) → text input (placeholder "CA") ; "ZIP *" (right third) → text input.
    - Second fieldset titled "Credit Status" (title at fieldset-top-left):
      - Row 1: "Approximate Score Range" (left half) → select dropdown (visible option "600-649") ; "Goal" (right half) → select dropdown (visible option "Buy a home").
      - Row 2: "Total Unsecured Debt ($)" (left half) → text input ; "# of Negative Items" (right half) → text input.
      - Row 3 (full width): "Notes (optional)" → multi-line textarea.
    - Below fieldsets, a checkbox row: unchecked checkbox followed by label text "I authorize Restore Credit Co. to contact me about my consultation request. I understand this is not a binding agreement."
    - Bottom row (form-bottom-left): primary button "Submit My Request" then secondary outlined button "Clear".
- Footer: same as home.

All inputs shown empty.
