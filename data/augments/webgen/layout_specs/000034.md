# Layout spec

## Screen: home
- Header (top of viewport, full width, separated by a horizontal divider): wordmark "Steel Blue Realty" at header-left (top line), tagline "Find your next home from our curated listings." directly below the wordmark at header-left.
- Main content (below header, centered column with a small left/right margin):
  - Filter card (top of main, full-width bordered card):
    - Row 1 (card-top): label "Search" at top-left of card, immediately below it a full-width text input with placeholder "Search by title, city, or keyword".
    - Row 2 (card-bottom): four labeled fields in a row plus a button at the far right. Left-to-right: "Type" → select dropdown showing "All"; "Min Price" → number input showing "0"; "Max Price" → number input showing "Any"; "Min Bedrooms" → number input showing "0"; then a "Reset" button at row-right.
  - Results count (below filter card, aligned to main-left): "8 properties found".
  - Property grid (below count): three columns × multiple rows of property cards. Visible cards in order:
    - Row 1: "Sunny Downtown Loft" (Apartment), "Cozy Suburban House" (House), "Beachfront Villa" (Villa).
    - Row 2: "Mountain Cabin Retreat" (Cabin), "Modern City Condo" (Condo), "Historic Brownstone" (House).
    - Row 3 (two cards, left-aligned with empty third column): "Lakeside Apartment" (Apartment), "Desert Modern Estate" (Villa).
  - Each property card structure (top-to-bottom inside the card):
    - Card-top: solid filled banner area with the property type label centered (e.g. "Apartment").
    - Card-middle: title in larger text at card-left (e.g. "Sunny Downtown Loft"); below it a single line of meta "City · X bd · X ba · XXXX sqft" at card-left; below that the price in bold at card-left (e.g. "$750,000").
    - Card-bottom: full-width "View Details" button.
- Footer (bottom of viewport, full width, separated by a horizontal divider above it): "© 2026 Steel Blue Realty" at footer-center.

## Screen: filters-reset

- Main content (below header):
  - Filter card (top of main, full-width bordered card) — all inputs in their default/empty state:
    - Row 1 (card-top): "Search" label at top-left, full-width text input below it with placeholder "Search by title, city, or keyword" (empty).
    - Row 2 (card-bottom): "Type" select showing "All"; "Min Price" input showing "0"; "Max Price" input showing "Any"; "Min Bedrooms" input showing "0"; "Reset" button at row-right.
  - Results count (below filter card, main-left): "8 properties found".
  - Property grid (below count): three-column grid identical to the home screen, eight property cards in three rows (last row has two cards, third column empty). Card layout matches the home screen (type banner at card-top, title/meta/price at card-middle, "View Details" button at card-bottom).
- Footer (bottom of viewport): "© 2026 Steel Blue Realty" at footer-center, above-divider horizontal rule.
