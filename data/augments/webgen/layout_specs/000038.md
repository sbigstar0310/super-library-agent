# Layout spec

## Screen: browse
- Header (top of viewport, full width, maroon band):
  - header-left: circular "S" avatar badge followed by wordmark "StayNest".
  - header-right: three nav items in a row — "Browse" (highlighted as a filled pill, current page), "My Bookings" (text link), "Log in" (text link).
- Main content (below header, two-column layout):
  - Sidebar (middle-left, narrow column): a "Search & Filter" card.
    - card-top: heading "Search & Filter" with an underline rule beneath.
    - Stacked form fields (top to bottom): label "Search" → text input (placeholder "Name or description"); label "Type" → select (placeholder "Any type"); label "City" → select (placeholder "Any city"); label "Max price/night ($)" → numeric input; label "Min guests" → numeric input.
    - card-bottom: full-width "Reset filters" button (outlined, maroon text/border).
  - Listing region (middle-right, wide column):
    - Top row of region: title "Available Apartments" at region-top-left; "8 results" counter at region-top-right.
    - Grid of apartment cards in a 3-column layout, rows of cards stacked vertically. Eight cards total — three full rows of three would be expected, but the last row contains only two cards leaving one empty slot at row-right.
    - Each card structure (top to bottom):
      - card-top: image placeholder area (rectangular, full card width).
      - Below image: apartment name at card-left, rating chip "★ 4.x" at card-right on the same line.
      - Next line: meta row — "<Type> · <City> · up to N guests".
      - Description paragraph (2 lines).
      - card-bottom row: price "$NNN/night" at card-bottom-left; filled maroon "View & Book" button at card-bottom-right.
    - Visible cards in order: "Sunny Studio in Downtown" $95, "Cozy 1BR Loft" $130, "Modern 2BR with Skyline View" $210, "Family 3BR Townhouse" $320, "Beachside Studio" $110, "Luxury 2BR Penthouse" $450, "Quiet 1BR Garden Flat" $120, "Historic 3BR Brownstone" $280.
- Footer (bottom of viewport, full width, lighter band): centered text "StayNest · Short-term apartment rentals".
