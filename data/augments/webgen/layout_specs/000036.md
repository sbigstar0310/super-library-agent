# Layout spec

## Screen: home
- Header: top-left of viewport — primary title "Cross-State Price Compare" at header-left; below the title, a subtitle line "Search products and compare prices across U.S. states."
- Main content: top-center, directly below the header — a single bordered rectangular panel spanning most of the viewport width.
  - Inside the panel (panel-top, arranged as a single horizontal row, left-to-right):
    - First column (panel-left): label "Category" above a dropdown showing "Electronics".
    - Second column: label "Max Price ($)" above a text input with placeholder "any".
    - Third column: label "Min Quantity" above a text input with placeholder "any".
    - Fourth column (panel-right): a filled primary button labeled "Search", vertically aligned with the inputs (not the labels).
- Forms: Category → dropdown ("Electronics") | Max Price ($) → numeric text input ("any") | Min Quantity → numeric text input ("any") → submit "Search". Form sits in the top panel, top-center of viewport.
- Interactive elements: "Search" primary button at panel-right; Category dropdown at panel-left; two text inputs between them.
- Empty state: the area below the search panel (middle and bottom of viewport) is empty.

## Screen: search-results
- Header: top-left of viewport — title "Cross-State Price Compare" at header-left with subtitle "Search products and compare prices across U.S. states." directly beneath it.
- Search panel: directly below the header, top-center — a bordered row containing, left-to-right: "Category" dropdown ("Electronics"), "Max Price ($)" input ("any"), "Min Quantity" input ("any"), and a primary "Search" button at panel-right. (Same panel as on the home screen.)
- Main content: stacked vertically below the search panel.
  - Section 1 (upper-middle): heading "Lowest Prices by Product" at section-top-left. Beneath it, a vertical list of rows, one per product. Each row has:
    - Product name at row-left (e.g., "Bluetooth Speaker", "Wireless Headphones", "Mechanical Keyboard", "4K Monitor 27\"").
    - Right-aligned metadata at row-right showing state, price, quantity, and supplier (e.g., "Arizona — Bluetooth Speaker — $44.55 ... qty 55").
    - A horizontal divider separates each row.
  - Section 2 (lower portion, extending to bottom): heading "All Results (40)" at section-top-left. To the right of this heading, a small inline controls cluster at section-top-right showing two dropdowns labeled "State" (value "All") and "Sort" (value "Price (low → high)").
    - Below the heading, a table spanning the section width with column headers in a single row: "Product", "State", "Price", "Quantity", "Supplier".
    - Table body: many rows of product data, alternating row background shading. Columns left-to-right: product name, state, price (dollar amount), quantity (integer), supplier name. Rows continue to the bottom of the viewport.
- Interactive elements: "Search" primary button at search-panel-right; "State" dropdown and "Sort" dropdown at the top-right of the "All Results" section.
- Empty state: none visible.
