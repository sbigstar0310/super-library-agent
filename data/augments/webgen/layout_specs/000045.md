# Layout spec

## Screen: login
- Header: top of viewport, full width — wordmark "Paper Cup Manufacturing System" at header-left; at header-right the text "User: admin" followed by a "Logout" button.
- Navigation bar: directly below the header, full width — a horizontal row of tab-style links, from tab-bar-left to tab-bar-right: "Dashboard" (visually selected/highlighted), "Raw Materials", "Products", "Inventory", "Production", "Sales", "Customers", "Reports".
- Main content: top-center of the page below the nav, stacked as two full-width bordered panels:
  - First panel "Overview": title at panel-top-left; below it, a single horizontal row of six equal-width metric tiles spanning panel-left to panel-right. Each tile shows a small caption label above a large numeric value. In order left-to-right: "Raw Materials (units) / 800", "Finished Products (units) / 260", "Customers / 2", "Sales Orders / 0", "Total Revenue / $0.00", "Production Runs / 0".
  - Second panel "Low Stock Alert": title at panel-top-left; below it, a table header row spanning panel-left to panel-right with three columns: "Item", "Type", "Stock". No data rows visible (empty state).
- Interactive elements: "Logout" button (top-right); eight nav tabs (below header); no buttons inside panels.

## Screen: materials
- Header: top of viewport — wordmark "Paper Cup Manufacturing System" at header-left; "User: admin" and "Logout" button at header-right.
- Navigation bar: below header — tabs left-to-right; "Raw Materials" is selected.
- Main content: below nav, four stacked full-width bordered panels:
  - Panel 1 "Add Raw Material" (top): heading at panel-top-left. Form row spanning panel-left to panel-right with four labeled text inputs in a row: "Name", "Unit", "Initial Stock", "Unit Cost". Below the row at panel-bottom-left: primary button "Add Material".
  - Panel 2 "Purchase Raw Material": heading at panel-top-left. Form row with three fields left-to-right: "Material" (dropdown showing "Select"), "Quantity" (text input), "Unit Cost (optional)" (text input). Below at panel-bottom-left: primary button "Record Purchase".
  - Panel 3 "Raw Materials List": heading at panel-top-left. Table spanning panel-left to panel-right with header columns: "ID", "Name", "Unit", "Stock", "Unit Cost", "Value", plus a trailing empty column for actions. Three data rows:
    1. 1, Paper Roll, roll, 500, $8.00, $4000.00, "Delete" button.
    2. 2, Ink, liter, 100, $12.00, $1200.00, "Delete" button.
    3. 3, Coating, kg, 200, $5.00, $1000.00, "Delete" button.
  - Panel 4 "Purchase History" (bottom): heading at panel-top-left. Table header only with columns "Date", "Material", "Qty", "Unit Cost", "Total"; no data rows (empty state).
- Interactive elements: "Add Material", "Record Purchase", per-row "Delete" buttons (destructive style), "Logout".
