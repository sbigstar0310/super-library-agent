# Layout spec

## Screen: home
- Header (top of viewport): wordmark "Q&A Hub" at header-left (large), tagline "Ask questions. Share answers. Rate the best ones." directly beneath it at header-left. A horizontal divider runs across the bottom edge of the header.
- Main content (center column, page-middle):
  - Top section "Ask a Question": section heading at section-top-left, with a horizontal divider beneath it. Below sits a bordered card (page-center) containing a vertical form.
  - Forms — Ask a Question card (top region of main):
    - "Title" label (top-left of card) → single-line text input (full width of card) with placeholder "What is your question?"
    - "Details" label → multi-line textarea (full width, ~5 rows) with placeholder "Add context, details, or examples..."
    - "Your name (optional)" label → single-line text input (full width) with placeholder "anonymous"
    - Submit button labeled "Submit Question" at card-bottom-left (primary, filled).
  - Middle section "Questions (1)": section heading at section-top-left with a horizontal divider beneath it.
  - Below the heading: a bordered question card (page-center) containing, stacked top to bottom:
    - Question title "What is React?" at card-top-left (heading style, link-like).
    - "Asked by newbie" meta line at top-left beneath the title.
    - Question body text "I keep hearing about React. What is it exactly?" left-aligned.
    - A row at card-middle-left: button labeled "Answer this question" (primary, filled) followed by inline text "1 answer".
    - Answer block at card-bottom (bordered sub-card, full inner width):
      - Answer body text at sub-card-top-left: "React is a JavaScript library for building user interfaces, maintained by Meta."
      - Author meta "— admin" at sub-card-middle-left.
      - Average rating "Avg 4.7 / 5 (3)" at sub-card-middle-right (same row as author meta).
      - At sub-card-bottom-left: label "Rate this:" followed by a row of five small buttons labeled "1★", "2★", "3★", "4★", "5★".
- Footer (bottom of viewport, center): text "Q&A Hub © 2026".

## Screen: ask-question-filled
- Header (top of viewport): same as home — "Q&A Hub" wordmark at header-left, tagline beneath, divider underneath.
- Main content (center column):
  - "Ask a Question" section heading at section-top-left with a divider beneath.
  - Ask a Question card (page-center) with the same form structure as home, now showing entered values:
    - Title input contains "How do I use hooks?"
    - Details textarea contains "I want to learn about React hooks."
    - Your name (optional) input contains "curious" (this input is shown with an emphasized/focused border).
    - "Submit Question" button at card-bottom-left.
  - "Questions (1)" section heading with divider, followed by the same question card for "What is React?" identical to the home screen (question title, asked-by, body, "Answer this question" button + "1 answer", and the answer sub-card with rating average and 1★–5★ buttons).
- Footer (bottom of viewport, center): "Q&A Hub © 2026".

## Screen: answer-form-open
- Header (top of viewport): same as other screens — "Q&A Hub" wordmark at header-left, tagline beneath, divider.
- Main content (center column):
  - "Ask a Question" section (top) with the same empty form card (Title / Details / Your name (optional) / "Submit Question" button) as on home.
  - "Questions (1)" heading with divider.
  - Question card (page-center) for "What is React?":
    - Title at card-top-left, "Asked by newbie" beneath.
    - Body "I keep hearing about React. What is it exactly?" beneath.
    - Row at card-middle-left: button labeled "Cancel" (replacing the "Answer this question" button) followed by inline text "1 answer".
    - Inline answer form (dashed-bordered sub-card, full inner width, positioned between the Cancel row and the existing answer):
      - Multi-line textarea at sub-card-top with placeholder "Write your answer..."
      - Single-line input beneath with placeholder "Your name (optional)".
      - Button at sub-card-bottom-left labeled "Post Answer" (primary, filled).
    - Existing answer sub-card at card-bottom: body text "React is a JavaScript library for building user interfaces, maintained by Meta.", "— admin" at middle-left, "Avg 4.7 / 5 (3)" at middle-right, and the "Rate this:" row with 1★–5★ buttons at sub-card-bottom-left.
- Footer (bottom of viewport, center): "Q&A Hub © 2026".
