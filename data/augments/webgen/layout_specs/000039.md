# Layout spec

## Screen: login
- Header: top of viewport, full-width band — wordmark "Domain Leasing Hub" at header-left; at header-right, text "Welcome, **admin** (admin)" followed by a "Logout" outlined button.
- Nav bar: directly below header, full-width band, aligned to nav-left — a horizontal row of outlined pill buttons in order: "Search" (filled/active state), "My Domains", "Orders", "Payments", "Lease Records", "Users".
- Main content: below nav, centered column.
  - Section title "Search Domains" at top-left of main.
  - Card filling the main width:
    - Card-top: a row with a wide text input placeholder "Search domain name…" on the left and a dropdown select showing "All" at card-top-right.
    - Below the input row, a table header bar with columns left-to-right: "Domain", "Price (mo)", "Status", "Owner", "Action".
    - Table body: six rows. Each row has a domain name (left), a price (e.g. "$120"), a small filled "available" pill badge in the Status column, an em-dash "—" in Owner, and a filled "Lease" button at row-right. Rows in order: starlight.com / $120, meadowfox.io / $95, rosybrown.dev / $180, oldlace.shop / $80, velvetbloom.net / $140, amber-grove.org / $110.
- Footer: bottom of viewport, centered text "© 2026 Domain Leasing Hub".
