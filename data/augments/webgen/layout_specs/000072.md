# Layout spec

All screens share the same top-of-viewport profile card and a navigation row directly below it, plus a footer line at the bottom-center of the viewport. The page background is light pink; primary text and accent UI elements are in a deep violet-red.

Shared chrome (present on every screen):
- Profile card (top of viewport, full width with side gutters):
  - Card-left: circular avatar with monogram "JR".
  - Card-center-left (to the right of the avatar): name "Jane Rosewood" (primary heading), with subtitle "Senior Frontend Engineer" directly below it, and a single line of contact text below that reading "jane.rosewood@example.com • San Francisco, CA • linkedin.com/in/janerosewood".
- Navigation row (directly below the profile card, full width with side gutters):
  - Five pill-shaped tab buttons in a single horizontal row at row-left: "About", "Experience", "Skills", "Education", "Projects". The active tab is rendered as a filled (solid) pill; inactive tabs are outlined pills. Order is identical on every screen.
- Footer (bottom-center of viewport, outside the main content card):
  - Single centered line: "© 2026 Jane Rosewood — Built with React".

## Screen: about
- Header: shared profile card at top of viewport (see Shared chrome). Active tab in the nav row below is "About" (filled pill at row-left).
- Main content: a single large card centered horizontally in the middle of the viewport, below the navigation row.
  - Card-top-left: section heading "About Me", with a thin horizontal divider line directly beneath it spanning the card width.
  - Below the divider (card-upper area): a multi-line paragraph of biography text reading "Passionate Senior Frontend Engineer with 8+ years of experience crafting performant, accessible web applications. I love building thoughtful user experiences using React, TypeScript, and modern web standards. Off-screen, you'll find me hiking trails, baking sourdough, or contributing to open source."
  - Below the paragraph (card-lower area): a 3-column × 2-row grid of small info tiles. Each tile has an uppercase label at tile-top-left and a value line below it. Reading order:
    - Row 1: "NAME" → "Jane Rosewood"; "EMAIL" → "jane.rosewood@example.com"; "PHONE" → "+1 (415) 555-0123".
    - Row 2: "LOCATION" → "San Francisco, CA"; "LANGUAGES" → "English, Spanish"; "AVAILABILITY" → "Open to opportunities".
- Forms: none.
- Interactive elements: the five nav pills in the shared nav row.
- Empty state / loading text: none.
