# Layout spec

## Screen: login
- Header: none.
- Main content: single card at center of viewport.
  - Card-top: recycle icon followed by wordmark "Recycle Heroes" (center-aligned), with tagline "Sort the trash. Save the planet!" directly below.
  - Card-middle: vertical form.
    - Label "Your name or email" (top-left of field) → text input with placeholder "admin or admin@example.com".
    - Label "Password" (top-left of field) → password input with placeholder "admin123456".
  - Card-bottom: full-width primary submit button "Start Playing" with a trailing icon, followed by a small helper line "Demo player: admin / admin123456" (center-aligned).
- Forms: name/email → text → password → password → submit "Start Playing"; form is the full content of the centered card.
- Interactive elements: text input (name/email), password input, primary button "Start Playing" (card-bottom, full width).
- Empty state / loading text: none visible.

## Screen: game
- Header: top of viewport, full-width rounded bar.
  - Header-top-left: recycle icon followed by wordmark "Recycle Heroes".
  - Header-bottom-left: row of three pill buttons — primary filled "Play" (active), outlined "Leaderboard", outlined "How to Play".
  - Header-middle (next to nav row): greeting text "Hi, admin!".
  - Header-right: outlined "Logout" button.
- Main content: vertical stack below header, page-center alignment.
  - Top region: full-width status bar with three columns — "Round 1 / 10" at bar-left, "Score: 0" at bar-center, "Correct: 0" at bar-right.
  - Middle region: large rounded card.
    - Card-top: prompt text "Where does this go?" (center-aligned).
    - Card-center: dashed-bordered tile containing a glyph at tile-top and the item label "Newspaper" at tile-bottom.
  - Bottom region: horizontal row of five equal-width bin cards (left → right): "Paper", "Plastic", "Glass", "Organic", "Metal". Each card has a glyph at card-top and the bin name at card-bottom.
  - Footer text: "Keep our Earth clean!" with a small icon, center-aligned, beneath the bin row.
- Forms: none.
- Interactive elements: nav buttons (Play / Leaderboard / How to Play) in header-bottom-left; "Logout" at header-right; five bin cards as click targets in bottom region.
- Empty state / loading text: none visible.

## Screen: how-to-play
- Header: same as game screen — wordmark and icon at header-top-left; pill nav at header-bottom-left with "How to Play" as the active filled pill and "Play", "Leaderboard" as outlined pills; "Hi, admin!" greeting to the right of the nav; outlined "Logout" at header-right.
- Main content: single large rounded card spanning page width below header.
  - Card-top: heading "How to Play" (center-aligned) with leading icon.
  - Card-upper: numbered list, left-aligned:
    1. "Look at the trash item in the middle."
    2. "Tap the bin where it belongs."
    3. "Get 10 points for each correct sort." (with "10 points" emphasized)
    4. "Earn cool badges and climb the leaderboard!"
  - Card-middle: sub-heading "Bin Guide" (left-aligned).
  - Card-bottom: grid of bin info tiles — first row has four tiles left→right: "Paper" (Newspapers, notebooks, cardboard. Keep them dry & clean.), "Plastic" (Bottles, cups, bags. Rinse before recycling.), "Glass" (Jars and bottles. Glass can be recycled forever!), "Organic" (Food scraps and yard waste become compost.). Second row has one tile at row-left: "Metal" (Cans and foil. Crush cans to save space.). Each tile has a small glyph at tile-top-left, bold bin name beside it, and description text below.
- Footer text: "Keep our Earth clean!" with a small icon, center-aligned, below the card.
- Forms: none.
- Interactive elements: header nav buttons, "Logout".
- Empty state / loading text: none visible.

## Screen: leaderboard
- Header: same structure as game screen — wordmark/icon at header-top-left; pill nav at header-bottom-left with "Leaderboard" as the active filled pill, "Play" and "How to Play" outlined; "Hi, admin!" greeting; "Logout" at header-right.
- Main content: single rounded card spanning page width below header.
  - Card-top: heading "Top Recyclers" (center-aligned) with leading icon.
  - Card-center: empty-state text "No scores yet. Be the first hero!" (center-aligned).
- Footer text: "Keep our Earth clean!" with a small icon, center-aligned, below the card.
- Forms: none.
- Interactive elements: header nav buttons, "Logout".
- Empty state / loading text: "No scores yet. Be the first hero!" shown at card-center.
