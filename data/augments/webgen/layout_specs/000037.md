# Layout spec

## Screen: customize
- Header: top of viewport — "Custom Shirt Studio" wordmark at header-left.
- Step indicator: below header, full-width row of four equal segments left-to-right: "1 Customize" (highlighted/active), "2 Preview", "3 Payment", "4 Confirmation". Each segment shows a numbered circle followed by the step label.
- Main content: below the step indicator, two outlined cards side-by-side filling the page-center.
  - Left card "Design Your Shirt" (card-left):
    - Title at card-top.
    - Form fields stacked vertically:
      - "Shirt Model" label → select dropdown (value: Classic).
      - "Fabric" label → select dropdown (value: Cotton).
      - "Color" label → color/text input field.
      - Row of two: "Collar" label → select (Spread) at row-left; "Cuff" label → select (Barrel) at row-right.
    - Sub-heading "Measurements" below.
    - Measurement inputs arranged in a 2-column grid:
      - Row 1: "Chest (in)" input (left), "Waist (in)" input (right).
      - Row 2: "Sleeve (in)" input (left), "Neck (in)" input (right).
      - Row 3: "Length (in)" input (left, single column).
  - Right card "Design Preview" (card-right):
    - Title at card-top.
    - Large dashed-bordered preview box at card-center containing a shirt outline illustration.
    - Below the preview box, a stacked list of attributes (label : value):
      - Model: Classic
      - Fabric: Cotton
      - Collar: Spread
      - Cuff: Barrel
      - Color: [swatch] #ffffff
    - At card-bottom: full-width filled bar reading "Price: $49.00".
- Interactive elements: "Continue to Preview" primary button at bottom-right under the cards.
- Footer: bottom-center — "Custom Shirt Studio © 2026".
