# Layout spec

## Screen: forum-all-posts
- Header: top of viewport, full width — wordmark "Campus Anon Forum" at header-left; at header-right (in order left→right): text "Signed in as **admin** (posts shown as anonymous)", "Notifications" button, "Logout" button.
- Sub-header banner: directly below header, full width — center-aligned notice text "Your username is never attached to posts or replies. Each contribution gets a random anonymous handle."
- Main content: two-column layout below sub-header banner.
  - Sidebar card (middle-left, narrow column): bordered panel containing two stacked groups.
    - Group 1 — header label "BROWSE" at top of card, followed by two stacked items: "All Posts" (highlighted as the active/selected item) and "Followed Topics".
    - Group 2 — header label "TOPICS" below the BROWSE group, followed by a vertical list of topic rows. Each row has the topic name at row-left and a small square "+" follow button at row-right. Topics in order: General, Courses, Campus Life, Career, Events.
  - Content card (middle-right, wide column): bordered panel that fills the remaining width.
    - Top of card: a horizontal row containing a "Search posts..." text input occupying the left/most of the width, and a primary "+ New Post" button at row-right.
    - Below the search row: a vertical list of post cards stacked top-to-bottom. Each post card contains:
      - Top row: a small topic tag/badge at card-top-left (e.g. "Courses", "Campus Life"); a relative timestamp at card-top-right (e.g. "2d ago", "5h ago").
      - Middle: bold post title (e.g. "Tips for CS101 final exam?"); below the title, the post body preview text.
      - Bottom row: an anonymous handle (e.g. "Anonymous Owl") at card-bottom-left; a reply count (e.g. "1 reply", "0 replies") at card-bottom-right.
    - Two posts visible: "Tips for CS101 final exam?" (Courses, 2d ago, Anonymous Owl, 1 reply) and "Best quiet spots on campus?" (Campus Life, 5h ago, Anonymous Cat, 0 replies).

## Screen: new-post-form
- Header: same as forum-all-posts.
- Sub-header banner: same anonymous-handle notice.
- Main content: same two-column layout.
  - Sidebar card (middle-left): BROWSE group with "All Posts" highlighted and "Followed Topics" below; TOPICS list with General, Courses, Campus Life, Career, Events, each with a "+" follow button at row-right.
  - Content card (middle-right): a form panel.
    - Card-top: heading "Create Anonymous Post".
    - Form fields stacked vertically below the heading, each as label-above-input full-width:

      - "Title" → single-line text input.
      - "Body" → multi-line textarea (tall).

    - Below the action row, left-aligned helper text in muted style: "Your username will not be attached. A random handle is generated for this post."

## Screen: register
- No header or sub-header banner — the viewport background fills the screen.
- Main content: a single centered card at the page-center (vertically and horizontally).
  - Card-top: bold title "Campus Anon Forum" centered, with a smaller centered tagline "Speak freely. Stay anonymous." directly beneath.
  - Tab row below the tagline: two tabs side-by-side, "Login" (left) and "Register" (right). "Register" is the active tab (emphasized with an underline indicator); "Login" is the inactive tab.
  - Form fields stacked vertically, each label-above-input, full card width:
    - "Username" → single-line text input.
    - "Email" → single-line text input.
    - "Password" → single-line password input.
  - Primary full-width button at form-bottom: "Create Account".
  - Below the button, centered muted helper text spanning two lines: "Your real identity is never displayed. Posts are signed with a generated anonymous name."
