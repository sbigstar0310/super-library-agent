# Layout spec

## Screen: groups
- Header: top of viewport, full width — "Virtual Study Group" wordmark at header-left; at header-right a row containing nav buttons "Groups" (active/highlighted), "Resources", "Projects", "Profile", then the text "Admin User", then a "Logout" button.
- Main content: page-center, stacked as two full-width panels with vertical spacing.
  - First panel (top): "Create a Group" — panel title at panel-top-left. Form stacked top-to-bottom: text input placeholder "Group name"; text input placeholder "Topic"; multi-line textarea placeholder "Description". A "Create Group" primary button at panel-bottom-left.
  - Second panel (below): "Available Groups" — panel title at panel-top-left. Below the title, a horizontal row of three group cards (first/second/third column).
    - Each card: title at card-top-left (e.g. "Algorithms 101", "Spanish Conversation", "Calculus Cruncher"), a category tag/badge at card-top-right ("Computer Science", "Languages", "Mathematics"); a one-line description in card-middle; at card-bottom a row with member count text at card-bottom-left (e.g. "1 member", "0 members") and an action button at card-bottom-right — "Leave" (outline) for joined groups, "Join" (filled) for non-joined.
- Forms: Group name → text input → "Create Group" (located in top panel).
- Interactive elements: nav buttons (header-right), "Logout" (header-far-right), "Create Group" (top panel bottom-left), per-card "Join"/"Leave" buttons (card-bottom-right).

## Screen: projects
- Header: top of viewport — "Virtual Study Group" at header-left; nav at header-right with "Groups", "Resources", "Projects" (active/highlighted), "Profile", then "Admin User" text, then "Logout" button.
- Main content: page-center, two stacked full-width panels.
  - First panel (top): "Create a Project" — title at panel-top-left. Vertical form: text input "Project name"; a select/dropdown showing "Algorithms 101"; multi-line textarea "Project description". A "Create Project" button at panel-bottom-left.
  - Second panel (below): "Projects & Discussions" — title at panel-top-left. Below the title, a vertical list of project cards stacked top-to-bottom.
    - Each project card: project title at card-top-left (e.g. "Build a Sorting Visualizer", "Travel Phrasebook"); a small group tag/badge at card-top-right (e.g. "Algorithms 101", "Spanish Conversation"); a one-line description below the title; a nested "Discussion" sub-card spanning card-bottom width:
      - Sub-card title "Discussion" at sub-card-top-left.
      - Below: message rows showing "<author>: <message>" (e.g. "admin: Let us start with bubble sort.") or an empty-state line ("No messages yet." plus a follow-up note such as 'Join "Spanish Conversation" to participate.').
      - At sub-card-bottom: a row with a text input placeholder "Add to the discussion..." at sub-card-bottom-left (stretched) and a "Post" button at sub-card-bottom-right. (The "Post" input row is hidden / not shown in the empty-state card.)
- Forms: Project name → Group select (defaults to "Algorithms 101") → Project description → "Create Project". Discussion: text input → "Post" per project card.
- Interactive elements: nav buttons (header-right), "Logout", "Create Project", per-card "Post".
