# Layout spec

Shared across all screens:
- Page background is light pink. Primary text, borders, and accents are medium violet red.
- Header (top of viewport): wordmark "Customer Service Call Log" at header-left; at header-right the text "admin" followed by a dropdown select showing "Admin". A horizontal divider runs below the header.
- Nav bar (below header, full width): a row of outlined pill/rounded buttons at nav-left, in order: "New Call", "Open Calls", "To-Do Calls", "Reports", "Clients", "New Client Wizard". The button matching the current screen is shown filled (highlighted) while the others are outlined.
- Main content sits inside a single bordered card (page-center, below the nav), with the screen title at card-top and a horizontal divider beneath the title.
