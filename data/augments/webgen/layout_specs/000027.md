# Layout spec

## Screen: browse
- Header: top of viewport — wordmark "DealShare Community" at header-left with tagline "Share deals. Save together." directly beneath it; three buttons in a row at header-right in order "Browse" (secondary outline), "Share a Deal" (secondary outline), "Admin" (primary filled). A thin divider line runs across the bottom edge of the header.
- Main content: page-center, stacked vertically.
  - Top block (filter card, page-top): card with heading "Find a Deal" at card-top-left. Below the heading, a single row with three controls: a wide search text input (placeholder "Search promotions, stores, codes…") at row-left, a dropdown labeled "All" in the middle, and a dropdown labeled "Most popular" at row-right. Beneath the row, text "3 deals found" at card-bottom-left.
  - Below the filter card, a vertical list of three deal cards, each card a wide rectangle stacked top to bottom.
    - Each deal card layout:
      - Card-left column: an upvote triangle "▲" at top, a numeric vote count in the middle (e.g. "27", "12", "9"), and a downvote triangle "▼" at bottom.
      - Card-top body: deal title (e.g. "Buy 1 Get 1 — Running Shoes") at body-top-left; a discount badge (e.g. "-50%", "-50%", "-20%") at card-top-right.
      - Card-middle body: meta line "Store · Category · by author · date" (e.g. "TrailRunner · Sports · by bob · 2026-05-12").
      - Card-middle body below meta: short description text (e.g. "Applies to last-season models. In-store and online.").
      - Card-bottom: a pill labeled "Code: BOGORUN" (or BREW50 / SOUND20) at bottom-left; link "Visit deal →" at bottom-right.
- Footer: bottom of viewport, center-aligned text "© 2026 DealShare Community — community-curated savings."

## Screen: share
- Header: same as browse — wordmark + tagline at header-left; "Browse", "Share a Deal" (this one shown as active/filled), "Admin" buttons at header-right.
- Main content: a single centered card on the page-center.
  - Card-top: heading "Share a Deal" at card-top-left; subtitle "Help the community save — share a promotion you've found." directly beneath.
  - Form (inside the card, stacked top to bottom):
    - "Title *" → single-line text input (placeholder "40% off summer dresses"), full card width.
    - Row of two fields side by side: "Store *" → text input (placeholder "StoreName") at row-left; "Category" → dropdown (showing "Food") at row-right.
    - Row of two fields side by side: "Discount (%)" → number input (placeholder "10") at row-left; "Promo code" → text input (placeholder "SAVE40") at row-right.
    - "Link" → text input (placeholder "https://…"), full card width.
    - "Description *" → multi-line textarea (placeholder "Details, restrictions, expiry…"), full card width, several lines tall.
    - "Your username (optional)" → text input (placeholder "janedoe"), full card width.
  - Card-bottom: submit button labeled "Post Promotion" at card-bottom-right (primary filled, contrasting accent).
- Footer: bottom of viewport, center-aligned "© 2026 DealShare Community — community-curated savings."

## Screen: admin-users
- Header: same as other screens — wordmark + tagline at header-left; "Browse", "Share a Deal", "Admin" buttons at header-right (Admin appears as the active primary).
- Main content: a single wide card on page-center.
  - Card-top: heading "Management Backend" at card-top-left.
  - Tab strip directly beneath the heading, left-aligned, three tabs in a row: "Users (4)" (active, filled darker), "Promotions (3)", "Site Settings".
  - Below the tabs, an inner darker panel containing:
    - Top row (panel-top): "New username" text input at row-left, a role dropdown (showing "member") next to it, then an "Add user" button (filled accent) at row-right of this top row.
    - A table below the top row with columns "Name", "Role", "Joined", "Status", and an unlabeled action column.
      - Header row at table-top.
      - Four data rows: alice / member dropdown / 2026-01-04 / Active badge / Delete button; bob / member dropdown / 2026-02-11 / Active badge / Delete button; carol / moderator dropdown / 2026-03-21 / Active badge / Delete button; dave / member dropdown / 2026-04-30 / Suspended badge / Delete button.
      - Status badges are pill-shaped at column-center; "Delete" buttons (outlined, red) at right of each row.
- Footer: bottom of viewport, center-aligned "© 2026 DealShare Community — community-curated savings."
