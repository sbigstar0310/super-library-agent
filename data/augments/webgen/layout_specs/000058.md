# Layout spec

## Screen: login
- Header: top of viewport, full width — wordmark "Coaching Match" at header-left. No nav and no user info on this screen.
- Main content: centered card in the upper-middle of the viewport on a beige background.
  - Card-top: heading "Login".
  - Below the heading, a vertical stack of two labeled inputs:
    - "Username or Email" label → single-line text input (full card width).
    - "Password" label → single-line text input (full card width).
  - Below the inputs, a primary CTA button "Login" at card-left.
  - Below the CTA, a row at card-left: caption text "Don't have an account?" followed by a secondary button "Register".
  - Card-bottom: small helper line "Demo: admin / admin@example.com / admin123456".

## Screen: register
- Header: top of viewport, full width — wordmark "Coaching Match" at header-left. No nav or user info.
- Main content: centered card in the upper-middle of the viewport on a beige background.
  - Card-top: heading "Register".
  - Vertical stack of four labeled single-line inputs, each label above its input, full card width:
    - "Username" → text input
    - "Email" → text input
    - "Full Name" → text input
    - "Password" → text input
  - Below the inputs, a primary CTA button "Register" at card-left.
  - Below the CTA, a row at card-left: caption text "Already registered?" followed by a secondary button "Login".
  - Card-bottom: small helper line "Demo: admin / admin@example.com / admin123456".

## Screen: profile
- Header: top of viewport, full width — wordmark "Coaching Match" at header-left; at header-right, greeting text "Hello, Admin User" followed by a "Logout" button.
- Nav bar: directly below the header, full width — a horizontal row at nav-left of five tab-style buttons in order: "Profile" (active/highlighted), "Personality Assessment", "Find Coach", "Sessions", "Goals".
- Main content: a large bordered card spanning most of the viewport width, anchored to the top-center below the nav.
  - Card-top: heading "My Profile".
  - Vertical stack of labeled fields, each label above its control, controls span full card width:
    - "Name" → text input (prefilled "Admin User").
    - "Bio" → multi-line textarea (prefilled "Demo account.").
    - "Interests (comma separated)" → text input (prefilled "Leadership, Productivity").
    - "Email" → text input (prefilled "admin@example.com").
    - "Personality Type" → text input (prefilled "Not assessed").
  - Card-bottom-left: primary CTA button "Save Profile".

## Screen: assessment
- Header: top of viewport — wordmark "Coaching Match" at header-left; "Hello, Admin User" and "Logout" at header-right.
- Nav bar: directly below header, full width — same five tab buttons at nav-left, with "Personality Assessment" active.
- Main content: a large bordered card spanning most of the viewport width, anchored top-center below the nav.
  - Card-top: heading "Personality Assessment".
  - Below the heading, descriptive line: "Answer the questions below to discover your coaching personality type."
  - Below that, a vertical list of five question blocks, separated by horizontal dashed dividers. Each block contains:
    - A bold question label (numbered 1–5) at block-top-left.
    - Four radio options stacked vertically below, each as a radio circle followed by the option text, left-aligned.
  - The five questions and their options:
    1. "When facing a problem I prefer to:" — Analyze data carefully / Trust intuition / Act decisively / Discuss with others.
    2. "My ideal coaching session focuses on:" — Career growth plans / Self-reflection / Concrete metrics / Relationships.
    3. "I am energized by:" — Big visions / Helping people / Solving puzzles / Hitting targets.
    4. "A great mentor would:" — Challenge my thinking / Listen deeply / Push me to act / Inspire new ideas.
    5. "I tend to plan by:" — Setting clear KPIs / Imagining future states / Reviewing past lessons / Aligning with team goals.
  - Card-bottom-left: CTA button "Submit Assessment".

## Screen: coaches
- Header: top of viewport — wordmark "Coaching Match" at header-left; "Hello, Admin User" and "Logout" at header-right.
- Nav bar: directly below header — five tab buttons at nav-left, with "Find Coach" active.
- Main content: stacked regions on a beige background, each region a bordered card spanning most of the viewport width.
  - Top region (search card, top-center):
    - Card-top-left: heading "Find a Coach".
    - Below heading, a row: a full-width text input "Search by name or specialty" on the left, and a dropdown select labeled "All" on the right.
    - Below the row, helper line: "Tip: complete the personality assessment to see match scores."
  - Middle/bottom region (coach grid, below the search card): a grid of coach cards arranged three across in the first row and continuing into a second row.
    - Each coach card contains, top-to-bottom and left-aligned:
      - Coach name as heading at card-top (e.g. "Sarah Brown").
      - Specialty line below the name (e.g. "Career Coaching").
      - Short description paragraph (e.g. "Helps professionals advance their careers.").
      - A horizontal row of small tag pills (e.g. "Analytical", "Driven").
      - "Rating: X.X / 5" line.
      - Card-bottom-left: primary CTA button "Book Session".
    - First row left-to-right: "Sarah Brown" / Career Coaching / tags Analytical, Driven / 4.8; "Marcus Tan" / Mindfulness & Wellness / tags Empathetic, Reflective / 4.7; "Elena Rossi" / Leadership Development / tags Driven, Visionary / 4.9.
    - Second row, first column only: "David Kim" / Life Coaching / tags Empathetic, Visionary / 4.6.

## Screen: coaches-book-modal
- Underlying screen is the coaches screen (header, nav, "Find a Coach" search card, and coach grid all still visible behind a dimmed overlay).
- Modal: centered in the viewport, anchored at viewport-center, sized as a medium card overlaying the coach grid.
  - Modal-top-left: heading "Book session with Sarah Brown".
  - Below heading, vertical stack of labeled controls, full modal width:
    - "Date" label → date input (placeholder "mm/dd/yyyy" with a calendar icon at the right end).
    - "Time" label → time input (placeholder "--:-- --" with a clock icon at the right end).
    - "Notes" label → multi-line textarea.
  - Modal-bottom-left: a row with two buttons — primary "Confirm" then secondary "Cancel".

## Screen: goals
- Header: top of viewport — wordmark "Coaching Match" at header-left; "Hello, Admin User" and "Logout" at header-right.
- Nav bar: directly below header — five tab buttons at nav-left, with "Goals" active.
- Main content: a bordered card spanning most of the viewport width, anchored top-center below the nav.

  - Below the heading, a single horizontal row containing three controls left-to-right: a text input with placeholder "Goal title" (wide), a numeric input prefilled "100" (medium width), and a primary CTA button "Add Goal" at the row's right end.
