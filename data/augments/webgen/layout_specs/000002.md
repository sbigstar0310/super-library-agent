# Layout spec

## Screen: compare
- Header: top of viewport, full width — "Neighborhood Compare" wordmark at header-left; at header-right in a row: "Compare" button (filled/active), "Dashboard" button (outlined), "admin" text label, "Sign out" button (outlined).
- Main content: below header, split into two columns.
  - Left column (middle-left, narrow): stacked vertically.
    - Top card "Neighborhood Map": title at card-top, helper text "Click areas to add or remove them from the comparison." directly under the title. Below the text, an inset map panel containing a 3-column × 2-row grid of rectangular area tiles. Row 1: Oakwood, Riverdale, Midtown. Row 2: Brookside, Harbor, Summit.
    - Below it, card "Selected": title at card-top, value "None" directly under the title.
  - Right column (middle-right, wide): single card "Comparison" at column-top with title at card-top and body text "Select one or more neighborhoods on the map to compare." underneath. The rest of the right column is empty.
- Interactive elements: header buttons (Compare, Dashboard, Sign out); six area tiles (Oakwood, Riverdale, Midtown, Brookside, Harbor, Summit) act as toggle selectors.
- Empty state: "Selected: None" in the left column; "Select one or more neighborhoods on the map to compare." inside the Comparison card on the right.

## Screen: dashboard
- Header: top of viewport, full width — "Neighborhood Compare" wordmark at header-left; at header-right in a row: "Compare" button (outlined), "Dashboard" button (filled/active), "admin" text label, "Sign out" button (outlined).
- Main content: below header, split into two columns.
  - Left column (middle-left, narrow): stacked vertically, same as the compare screen.
    - "Neighborhood Map" card at top with helper text and the 3×2 grid of area tiles (Oakwood, Riverdale, Midtown / Brookside, Harbor, Summit).
    - "Selected" card below, value "None".
  - Right column (middle-right, wide): stacked vertically.
    - Toolbar row at column-top spanning full width of the column: label "Layout:" followed by two toggle buttons "Grid" (active/filled) and "Stack" (outlined); a vertical divider; label "Panels:" followed by a row of checkboxes with labels — Population (checked), Median Income (checked), Total Crime (checked), Home Value (unchecked), Median Age (unchecked).
    - Below the toolbar, a 2-column grid of panel cards.
      - Row 1, left: "Population" panel. Header row inside the card: title at panel-header-left; three small icon buttons at panel-header-right — up arrow, down arrow, close (X). Body of the card contains an inner card titled "Demographics: Population" with body text "Select neighborhoods to see this chart."
      - Row 1, right: "Median Income" panel. Same header pattern (title + up/down/close). Body inner card titled "Economic: Median Income ($)" with body text "Select neighborhoods to see this chart."
      - Row 2, left: "Total Crime" panel. Same header pattern. Body inner card titled "Crime: Total (per 1k)" with body text "Select neighborhoods to see this chart."
      - Row 2, right: empty slot.
- Interactive elements: header buttons; Layout toggle (Grid / Stack); five panel checkboxes; per-panel up / down / close controls; six area tiles in the map card.
- Empty state: each panel body shows "Select neighborhoods to see this chart."; "Selected: None" in left column.

- Main content: below header, split into two columns (identical to the compare screen — no dedicated login form is visible).
  - Left column (middle-left, narrow): "Neighborhood Map" card at top with title, helper text "Click areas to add or remove them from the comparison.", and the 3-column × 2-row grid of area tiles (Row 1: Oakwood, Riverdale, Midtown; Row 2: Brookside, Harbor, Summit). Below it, "Selected" card with value "None".
  - Right column (middle-right, wide): "Comparison" card at column-top with title and body text "Select one or more neighborhoods on the map to compare." The rest of the right column is empty.
- Interactive elements: header buttons (Compare, Dashboard, Sign out); six area tiles in the map card.
- Empty state: "Selected: None" in the left column; "Select one or more neighborhoods on the map to compare." on the right.
