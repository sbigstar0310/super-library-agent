# Layout spec

## Screen: get-started
- Header: top of viewport, full-width bar — wordmark "Student Portal" at header-left; three buttons in a row at header-right in order Home, Login, Register (Register appears as the active/highlighted button).
- Main content: a single bordered card spanning most of the page width, positioned at top-center just below the header.
  - Card-top-left: heading "Register".
  - Below heading, stacked vertically aligned to card-left (form occupies roughly the left half of the card width).
- Forms:
  - "Username" label → single-line text input
  - "Email" label → single-line text input
  - "Password" label → single-line password input
  - Submit: full-width (matching input width) primary button labeled "Create Account" at card-bottom of the form column.
- Interactive elements: Home, Login, Register buttons (header-right); Create Account primary button (inside card, below Password).

## Screen: home
- Header: top of viewport, full-width bar — wordmark "Student Portal" at header-left; Home, Login, Register buttons in a row at header-right (Home appears active/highlighted).

## Screen: matches
- Header: top of viewport, full-width bar — wordmark "Student Portal" at header-left; at header-right a row of: Profile, Matches (active/highlighted), My Applications, Provider View buttons, then plain text "Hi, admin", then a Logout button.
- Main content: a single outer bordered card at top-center just below header, spanning most of viewport width.
  - Outer-card-top-left: heading "Matched Training Providers".
  - Below heading: a vertical list of inner bordered provider cards, each card full-width within the outer card, stacked top-to-bottom.
- Each provider card layout (repeated for: Azure Tech Academy, Northern Lights Engineering, Midnight Health Institute, Blue Horizon Business School, Sapphire Creative Arts):
  - Card-top-left: provider name (bold heading).
  - Card-top-right: a small dark pill badge with white text "Match: <number>" (values seen: 100, 40, 15, 15, 15).
  - Below heading: a one-line short description (e.g. "Intensive cloud and software engineering bootcamps.").
  - Below description: a single line of meta text with bullet separators in the form "<Field> • <Location> • Requires <Qualification>" (e.g. "Computer Science • Seattle • Requires High School").
  - Below meta: a bulleted list (small circular bullets) of match reasons. Lists vary per card; examples observed:
    - Azure Tech Academy: "Field of study match", "Location match", "Qualification meets requirement", "Career interest match: Software Engineering, Cloud Computing"
    - Northern Lights Engineering: "Location match", "Qualification meets requirement"
    - Midnight Health Institute / Blue Horizon Business School / Sapphire Creative Arts: "Qualification meets requirement"
  - Card-bottom-left: primary button labeled "Apply".
- Interactive elements: header nav buttons (Profile, Matches, My Applications, Provider View, Logout); one "Apply" button per provider card.

## Screen: profile
- Header: top of viewport, full-width bar — wordmark "Student Portal" at header-left; at header-right: Profile (active/highlighted), Matches, My Applications, Provider View buttons, "Hi, admin" text, then Logout button.
- Main content: a single bordered card at top-center just below header.
  - Card-top-left: heading "My Profile".
  - Below heading: a vertically stacked form column aligned to card-left (occupies roughly the left half of the card width).
- Forms (top to bottom):
  - "Full Name" label → text input, prefilled "Admin User"
  - "Highest Qualification" label → dropdown select, currently "Bachelor"
  - "Location" label → text input, prefilled "Seattle"
  - "Field of Study" label → dropdown select, currently "Computer Science"
  - "Career Interests (comma separated)" label → text input, prefilled "Software Engineering, Cloud Computing"
  - "Bio" label → multi-line textarea, prefilled "Demo student account."
  - Submit: full-width primary button labeled "Save Profile" at the bottom of the form column.
- Interactive elements: header nav buttons; Save Profile primary button.

## Screen: provider-view
- Header: top of viewport, full-width bar — wordmark "Student Portal" at header-left; at header-right: Profile, Matches, My Applications, Provider View (active/highlighted) buttons, "Hi, admin" text, then Logout button.
- Main content: a single outer bordered card at top-center just below header.
  - Outer-card-top-left: heading "Provider View — Find Students".
  - Below heading: a one-line description "Filter the student directory by predefined criteria to reach candidates that fit your program."
  - Filter row: three controls side-by-side, aligned to card-left, each with a label above the control:
    - "Field" label → dropdown, currently "Any"
    - "Location" label → text input (empty)
    - "Min Qualification" label → dropdown, currently "Any"
  - Below the filter row: a list of result cards (one visible). Single result card layout:
    - Card-top-left: student name heading "Admin User".
    - Below name: meta line "Computer Science • Seattle • Bachelor".
    - Below meta: "Interests: Software Engineering, Cloud Computing".
    - Below interests: "Contact: admin@example.com" — the email is a hyperlink.
- Interactive elements: header nav buttons; three filter controls; the email link in the result card.
