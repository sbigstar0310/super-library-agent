# Layout spec

## Screen: claims
- Header (top of viewport, full width): wordmark "St. Claude General Hospital" at header-left with subtitle "Management System" stacked beneath it.
- Sub-header nav bar (directly below header, full width): a single row of pill buttons at nav-left in this order — "Finance", "Patient Records", "Pharmacy", "Laboratory", "Theater", "Claims", "Daily Reports", "Reports". The "Claims" button appears highlighted (active).
- Main content (top-center, framed card spanning most of the width with margins): card-top has title "Claim Formulation" with a horizontal divider beneath it.
  - Forms: card-middle — first row has three inputs in a row: "Patient" text input | "Insurer" text input | "Amount" text input. Below that, a wider multi-line "Claim description" textarea spans the full card width. Submit button "Create Claim" sits at form-left below the textarea.
  - Empty state: italic text "No claims yet." at card-bottom-left below the submit button.
- Footer (bottom of viewport, full width): "© Hospital Management System" centered.
