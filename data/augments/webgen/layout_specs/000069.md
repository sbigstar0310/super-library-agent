# Layout spec

## Screen: home
- Header: top of viewport, full width — "Health Blog" wordmark at header-left; at header-right in order: "Home" button, "Publish" button, "Hi, admin" text, "Logout" button.
- Main content: below header, two-column layout.
  - Left column (middle-left, wider): top holds a search row with a "Search articles..." text input filling most of the row and a "Search" button at its right end. Below the search row, a vertical stack of four article cards. Each card contains, from card-top to card-bottom: a category pill badge (e.g., "Nutrition", "Fitness", "Mental Health", "Sleep") at card-top-left; article title heading below the badge; a meta line "By admin · YYYY-MM-DD" beneath the title; a short excerpt paragraph; a "Read More" button at card-bottom-left.
  - Right column (middle-right, narrower): a "Categories" panel at panel-top with a heading and a horizontal divider below it. Beneath the divider, a vertical list of category entries: first entry "All Topics" (link style, no follow button); then "Nutrition", "Fitness", "Mental Health", "Sleep", "Wellness", each followed by a "Follow" button beneath the category name.
- Interactive elements: header nav buttons (Home, Publish, Logout); Search button; four "Read More" buttons; "All Topics" link; five "Follow" buttons.

## Screen: logout-home
- Header: top of viewport — "Health Blog" wordmark at header-left; at header-right in order: "Home", "Login", "Register" buttons.
- Main content: same two-column structure as home.
  - Left column: search row (input + "Search" button) at top, followed by the same vertical stack of four article cards (Nutrition/Fitness/Mental Health/Sleep) each with category pill, title, meta line, excerpt, and "Read More" button.
  - Right column: "Categories" panel with heading and divider. Entries: "All Topics" at top, then "Nutrition", "Fitness", "Mental Health", "Sleep", "Wellness", each with a "Follow" button below the category name.
- Interactive elements: Home/Login/Register in header; Search; four Read More; All Topics link; five Follow buttons.

## Screen: all-topics
- Header: identical to home (Health Blog left; Home, Publish, "Hi, admin", Logout right).
- Main content: two-column layout.
  - Left column: search row at top (input + "Search" button). Below it, the full vertical stack of four article cards (Nutrition, Fitness, Mental Health, Sleep) with pill, title, meta, excerpt, and "Read More".
  - Right column: "Categories" panel with heading and divider. First entry "All Topics" shown underlined/emphasized (active state). Below it: "Nutrition", "Fitness", "Mental Health", "Sleep", "Wellness" each with a "Follow" button beneath.
- Interactive elements: header nav; Search; Read More on each card; category link "All Topics" (active); five Follow buttons.

## Screen: category-nutrition
- Header: identical to home (Health Blog left; Home, Publish, "Hi, admin", Logout right).
- Main content: two-column layout.
  - Left column: search row at top (input + "Search" button). Below the search row, a filter status line reading "Filtering by: Nutrition". Beneath that, a single article card ("10 Superfoods You Should Eat Daily") with a "Nutrition" pill at card-top-left, title, meta "By admin · 2026-01-15", excerpt, and a "Read More" button at card-bottom-left.
  - Right column: "Categories" panel with heading and divider. Entries: "All Topics"; "Nutrition" (shown underlined/active) with a "Follow" button below; "Fitness", "Mental Health", "Sleep", "Wellness" each with "Follow" button.
- Interactive elements: header nav; Search; Read More; category links; four Follow buttons.

## Screen: follow-nutrition
- Header: identical to home (Health Blog left; Home, Publish, "Hi, admin", Logout right).
- Main content: two-column layout.
  - Left column: search row at top, then the full vertical stack of four article cards (as on home).
  - Right column: two stacked panels.
    - Top panel "Categories" (panel-top heading + divider): "All Topics"; "Nutrition" with an "Unfollow" button below it (instead of Follow); "Fitness", "Mental Health", "Sleep", "Wellness" each with "Follow" button.
    - Bottom panel "Following" (below the Categories panel): heading with divider, and a single item "Nutrition" listed below.
- Interactive elements: header nav; Search; Read More on each card; Unfollow (Nutrition); four Follow buttons; All Topics link.

## Screen: article-detail
- Header: identical to home (Health Blog left; Home, Publish, "Hi, admin", Logout right).
- Main content: single-column stack, page-center width.
  - Top: "← Back" button at top-left of the content area.
  - Middle: article card. Inside the card, from card-top: category pill "Nutrition" at card-top-left; article title heading "10 Superfoods You Should Eat Daily"; meta line "By admin · 2026-01-15"; body paragraphs of article content.
  - Bottom: Comments panel below the article card. Panel contents from panel-top: heading "Comments (0)"; empty-state line "No comments yet. Be the first!"; a multi-line "Write a comment..." textarea filling the panel width; a "Post Comment" button at panel-bottom-left below the textarea.
- Forms: comment form — (no visible label) → textarea "Write a comment..." → submit "Post Comment".
- Interactive elements: header nav; "← Back" button; "Post Comment" button.

## Screen: login
- Header: top of viewport — "Health Blog" wordmark at header-left; at header-right: "Home", "Login", "Register" buttons (Login shown in active/highlighted style).
- Main content: a centered card at top-center of the page.
  - Card-top: heading "Login".
  - Card-middle: stacked form. First field label "Username or Email" above a single-line text input. Second field label "Password" above a single-line text input.
  - Card-bottom: two buttons in a row at card-bottom-left — primary "Login" button, then secondary "Register" button.
- Forms: Username or Email → text input; Password → password input; submit "Login".
- Interactive elements: header Home/Login/Register; card "Login" submit; card "Register" button.

## Screen: register
- Header: top of viewport — "Health Blog" left; "Home", "Login", "Register" at header-right (Register in active/highlighted style).
- Main content: centered card at top-center of the page.
  - Card-top: heading "Register".
  - Card-middle: stacked form. Labels above inputs in order: "Username" → text input; "Email" → text input; "Password" → password input.
  - Card-bottom: two buttons in a row at card-bottom-left — primary "Register" button, then secondary "Back to Login" button.
- Forms: Username → text; Email → text; Password → password; submit "Register".
- Interactive elements: header nav; "Register" submit; "Back to Login" button.

## Screen: back-to-login
- Header: top of viewport — "Health Blog" left; "Home", "Login", "Register" at header-right (Login in active/highlighted style).
- Main content: centered card at top-center of the page, identical in structure to the login screen.
  - Card-top: heading "Login".
  - Card-middle: "Username or Email" label + text input; "Password" label + password input.
  - Card-bottom: "Login" primary button and "Register" secondary button in a row at card-bottom-left.
- Forms: Username or Email → text; Password → password; submit "Login".
- Interactive elements: header nav; "Login" submit; "Register" button.

## Screen: publish-new
- Header: top of viewport — "Health Blog" left; at header-right: "Home", "Publish" (active/highlighted), "Hi, admin", "Logout".
- Main content: centered card at top-center of the page.
  - Card-top: heading "Publish New Article".
  - Card-middle: stacked form. Labels above controls in order: "Title" → single-line text input; "Category" → dropdown select (default option shown "Nutrition"); "Content" → multi-line textarea.
  - Card-bottom: two buttons in a row at card-bottom-left — primary "Publish" button, then secondary "Cancel" button.
- Forms: Title → text; Category → select; Content → textarea; submit "Publish".
- Interactive elements: header nav; "Publish" submit; "Cancel" button.
