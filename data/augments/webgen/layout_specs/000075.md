# Layout spec

All five screens render the same single-page scrolling layout (the nav buttons in the header act as in-page anchors). The shared layout is described once below per screen.

## Screen: home
- Header (top of viewport, full width, solid dark-cyan band):
  - Wordmark "Northwind Studio" at header-top-center.
  - Tagline "A small team building delightful web products." at header-middle-center, directly below the wordmark.
  - Nav row at header-bottom-center: four outlined buttons in a single horizontal row — "Team", "Projects", "Skills", "Contact" (left-to-right).
- Main content (below header, full width, whitesmoke background) stacks four sections vertically:
  1. About the Team section (top).
  2. Project Showcase section (upper-middle, on a slightly darker band).
  3. Our Skills section (lower-middle).
  4. Contact Us section (bottom, on a slightly darker band).
- About the Team (section-top): heading "About the Team" at section-top-center; descriptive paragraph "We are a multidisciplinary group of engineers, designers, and product thinkers crafting tools that teams love to use." centered below the heading; three equal-width member cards in one horizontal row at section-bottom. Each card (dark-cyan fill): circular monogram avatar at card-top-center (letters "A", "M", "P"); member name centered below the avatar ("Ada Chen", "Miguel Ortiz", "Priya Rao"); role centered at card-bottom ("Lead Engineer", "Designer", "Product Manager").
- Project Showcase (section below About): heading "Project Showcase" at section-top-center; three equal-width project cards in one horizontal row at section-bottom. Each card (light fill, top-left aligned text):
  - Card 1: title "Harbor CMS" at card-top-left; description "A headless content management system focused on editorial workflows." in card-middle; tag pills row at card-bottom — "React", "Node.js", "PostgreSQL".
  - Card 2: title "Pulse Analytics"; description "Real-time analytics dashboard for SaaS products."; tags "TypeScript", "D3", "WebSocket".
  - Card 3: title "Beacon Mobile"; description "Cross-platform mobile app for field workers."; tags "React Native", "GraphQL".
- Our Skills (section below Projects): heading "Our Skills" at section-top-center; a vertically stacked list of five skill rows occupying the center column. Each row: skill label at row-left, percentage at row-right, horizontal progress bar spanning the full row width directly underneath the label. Rows top-to-bottom: "Frontend Development 95%", "Backend Development 88%", "UI / UX Design 82%", "DevOps & Cloud 75%", "Mobile Development 70%". Filled portion of each bar is dark-cyan; remainder is light gray.
- Contact Us (bottom section): heading "Contact Us" at section-top-center; two equal-width columns below the heading.
  - Left column — dark-cyan info card: three stacked lines at card-top-left, each with a bold label followed by value: "Email: hello@northwind.studio", "Phone: +1 (555) 123-4567", "Address: 42 Harbor Street, Seattle, WA".
  - Right column — contact form: stacked inputs top-to-bottom — text input labeled by placeholder "Your name", text input "Your email", multi-line textarea "Your message". Submit button "Send Message" (solid dark-cyan, full column width) at form-bottom.
- Footer (bottom of viewport, full width, solid dark-cyan band): centered text "© 2026 Northwind Studio. All rights reserved." at footer-center.

## Screen: team
Layout identical to `home`. The "Team" nav button in the header anchors to the About the Team section (upper portion of main content). See `home` for the full description of header, About the Team cards (Ada Chen / Miguel Ortiz / Priya Rao), and remaining sections.

## Screen: projects
Layout identical to `home`. The "Projects" nav button anchors to the Project Showcase section (three project cards in a row: Harbor CMS, Pulse Analytics, Beacon Mobile, each with title at card-top-left, description in card-middle, tag pills at card-bottom). See `home` for header, surrounding sections, and footer.

## Screen: skills
Layout identical to `home`. The "Skills" nav button anchors to the Our Skills section (five labeled progress-bar rows stacked vertically with percentages at row-right). See `home` for header, surrounding sections, and footer.

## Screen: contact
Layout identical to `home`. The "Contact" nav button anchors to the Contact Us section (two-column layout: dark-cyan info card at section-left with Email/Phone/Address lines; form at section-right with Your name, Your email, Your message inputs and a "Send Message" button at form-bottom). See `home` for header, surrounding sections, and footer.
