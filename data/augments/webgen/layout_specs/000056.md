# Layout spec

## Screen: login
- Header: none.
- Main content: card at viewport-center.
  - Card-top: wordmark "DataSci Learn" centered.
  - Below wordmark, centered: subtitle "Python Data Science — Online Learning Platform".
  - Card-middle: stacked form, full card width.
- Forms:
  - Label "Username or Email" → text input (placeholder "admin or admin@example.com").
  - Label "Password" → password input (placeholder "admin123456").
  - Submit button "Log in" full card width, directly below password field.
- Interactive elements: "Log in" button at card-bottom (above footer line).
- Footer line inside card-bottom (centered): "Demo account:" followed by two inline code chips "admin" / "admin123456".

## Screen: courses
- Header: top of viewport, full width.
  - Header-left: wordmark "DataSci Learn".
  - Header-right: row of nav buttons in order — "Courses" (active/highlighted), "My Grades", "Demo Admin", "Log out".
- Main content: below header, page padding on left/right.
  - Top row: title "Browse Courses" at top-left; at top-right a search input (placeholder "Search by title, instructor, topic...") and a dropdown select labeled "All".
  - Below top row: grid of course cards, 3 columns.
    - First row (left→right): "Python Basics for Data Science", "NumPy & Pandas Essentials", "Data Visualization with Matplotlib & Seaborn".
    - Second row (left): "Intro to Machine Learning with scikit-learn".
  - Each card layout:
    - Card-top-left: course title (bold, may wrap two lines).
    - Card-top-right: level badge pill ("Beginner", "Intermediate", "Intermediate", "Advanced").
    - Below title: meta line "Instructor · N weeks · N lessons".
    - Card-middle: description paragraph.
    - Card-bottom-right: "View Course" button.
- Footer: bottom of viewport, full width, centered text "© DataSci Learn — Python Data Science Online".

## Screen: course-detail
- Header: same as courses screen. "Courses" nav button shown unhighlighted; same four buttons at header-right.
- Main content: below header, page padding.
  - Top: "← Back to courses" button at top-left.
  - Below back button: hero card spanning content width.
    - Card-top-left: course title "Python Basics for Data Science".
    - Card-top-right: primary button "Enroll".
    - Below title: meta line "Dr. Ada Chen · 4 weeks · Beginner".
    - Below meta: description paragraph.
  - Below hero: two-column row.
    - Left column (narrower) — "Lessons" card.
      - Card-top: heading "Lessons".
      - Below heading: numbered list of lesson items (1–4). First item highlighted/selected ("Setting up Python & Jupyter"). Items 2–4: "Variables, Types, and Operators", "Control Flow & Functions", "Working with Files & Modules".
    - Right column (wider) — lesson detail card.
      - Card-top: lesson title "Setting up Python & Jupyter".
      - Below: lesson description paragraph "Install Python 3 and Jupyter Notebook. Practice running cells and writing print statements.".
  - Below two-column row: full-width "Assignment" card.
    - Card-top-left: heading "Assignment".
    - Below heading: prompt text "Write a script that reads a CSV of student scores and prints the average.".
    - Below prompt: label "Paste your Python code below." → multiline textarea (placeholder "Write or paste your answer here...").
    - Card-bottom-left: button "Submit Assignment".
- Footer: bottom of viewport, full width, centered "© DataSci Learn — Python Data Science Online".

## Screen: course-detail-enrolled
- Identical layout to course-detail with one difference: at hero card-top-right, in place of the "Enroll" button, a status pill/badge labeled "Enrolled" (non-button visual).
- Header, back button, lessons card, lesson detail card, assignment card, and footer match course-detail.

## Screen: grades

- Main content: below header, page padding.
  - Top row: title "My Grades" at top-left; at top-right summary "0 / 4 assignments submitted".
  - Below top row: full-width table card.
    - Table header row: columns "Course", "Assignment", "Submitted", "Grade" (no header label for the action column at far right).
    - Table body, 4 rows (top→bottom):
      1. Course "Python Basics for Data Science" | Assignment "Write a script that reads a CSV of student scores and prints the average." | Submitted "—" | Grade pill "Not submitted" | Action button "Open" at row-right.

      3. Course "Data Visualization with Matplotlib & Seaborn" | Assignment "Produce 3 plots from the Iris dataset and write a short caption for each." | Submitted "—" | Grade pill "Not submitted" | "Open".
      4. Course "Intro to Machine Learning with scikit-learn" | Assignment "Train a classifier on the Titanic dataset and report accuracy and confusion matrix." | Submitted "—" | Grade pill "Not submitted" | "Open".
- Interactive elements: one "Open" button per row, aligned at row-right.
- Footer: bottom of viewport, full width, centered "© DataSci Learn — Python Data Science Online".
