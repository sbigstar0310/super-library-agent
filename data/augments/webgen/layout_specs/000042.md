# Layout spec

Global chrome shared by every screen:
- Page background: cornsilk (pale cream), full viewport.
- Header panel (top-center, spanning most of the viewport width with side gutters, rounded corners, peru fill):
  - Wordmark `Peru Mail` at header-top-left.
  - Nav row at header-bottom-left, four pill buttons in a row: `Compose`, `Sent (0)`, `Templates`, `Recipients`. The button matching the current screen is rendered with a lighter/filled pill style (active state); the others use an outlined style over the peru fill.
- Main content panel below the header (top-center, same width as header, rounded corners, peru fill). Content varies per screen.

## Screen: compose
- Header: top-center — wordmark `Peru Mail` at header-top-left; nav row at header-bottom-left with `Compose` active.
- Main content: peru card directly below the header.
  - Title `Compose Email` at card-top-left.
  - Form stacks vertically, each field label left-aligned above its input, fields span full card width:
    1. `Use Template` label → select dropdown showing `— None —`.
    2. `Recipients` label → bordered list box containing two rows, each with an unchecked checkbox on the left and bold text: `Alice Johnson <alice@example.com>` (first row), `Bob Smith <bob@example.com>` (second row).
    3. Row with a text input placeholder `Add email address` (fills width) and an `Add` button at row-right (dark filled).
    4. `Subject` label → single-line text input (empty).
    5. `Body` label → multi-line textarea (empty, ~5 rows tall).
    6. `Attachments` label → file input control showing `Choose Files` button and helper text `No file chosen`.
  - `Send` button at card-bottom-left (pill, light fill).

## Screen: compose-filled
- Header: identical to compose screen, `Compose` active.
- Main content: same Compose Email card as [compose], but with values populated:
  - `Use Template` select still shows `— None —`.
  - `Recipients` list unchanged (both checkboxes unchecked).
  - `Add email address` input empty; `Add` button unchanged.
  - `Subject` input contains `Hello there`.
  - `Body` textarea contains `This is a test email body.` on the first line.
  - `Attachments` shows `No file chosen`.
  - `Send` button at card-bottom-left.

## Screen: sent
- Header: top-center — `Sent (0)` nav button rendered as active (filled).
- Main content: peru card below header.
  - Title `Sent Emails` at card-top-left.
  - Search input spanning full card width, placeholder `Search sent emails...`, positioned directly below the title.
  - Empty state text `No sent emails.` at card-middle-left directly beneath the search input.

## Screen: templates
- Header: top-center — `Templates` nav button rendered as active.
- Main content: peru card below header, split into two columns.
  - Left column (card-left, ~40% width): heading `Create Template` at column-top-left, followed by a vertical form:
    - `Name` label → single-line text input (empty).
    - `Subject` label → single-line text input (empty).
    - `Body` label → multi-line textarea (empty, ~5 rows tall).
    - `Save Template` button at column-bottom-left (pill, light fill).
  - Right column (card-right, ~55% width): heading `Saved (2)` at column-top-left, followed by a vertical stack of two template cards (light cream fill, rounded, bordered):
    - First card:
      - Title `Welcome` at card-top-left (bold, peru color).
      - Subheading `Subject: Welcome aboard!` beneath the title.
      - Preview block (slightly darker cream inset) with two lines: `Hi {name},` then `Welcome to our platform. We are excited to have you.`.
      - Row at card-bottom-left with `Use` link/button (text style) then `Delete` button (dark-red filled).
    - Second card (same structure):
      - Title `Follow-up`.
      - Subheading `Subject: Just checking in`.
      - Preview block: `Hi {name},` then `Just wanted to follow up on our previous conversation.`.
      - `Use` and `Delete` controls at card-bottom-left.

## Screen: recipients
- Header: top-center — `Recipients` nav button rendered as active.
- Main content: peru card below header.
  - Title `Recipients` at card-top-left.
  - Add row directly below title (spans card width): `Name` placeholder text input at row-left (~40% width), `Email` placeholder text input in the middle (~50% width), `Add` button at row-right (light pill).
  - Vertical stack of recipient cards below the add row (light cream fill, rounded, bordered, full card width):
    - First card: `Alice Johnson` bold heading at card-top-left (peru color); `alice@example.com` on the next line; `Delete` button (dark-red filled) at card-bottom-left.
    - Second card: `Bob Smith` bold heading at card-top-left; `bob@example.com` on the next line; `Delete` button at card-bottom-left.
