# Layout spec

## Screen: poll-list
- Header: top of viewport, centered — wordmark "Polls" at header-top-center, tagline "Cast your vote and see what others think" directly below at header-bottom-center. A horizontal divider line runs full-width beneath the header.
- Main content: center column below the header, centered horizontally with wide left/right margins.
  - Section title "Available Polls" at main-top-left.
  - A vertical stack of three poll cards beneath the title, each card a bordered rectangle spanning the column width.
    - Card 1 (first row):
      - Card-left: poll question "What is your favorite programming language?" at card-top-left; meta line "4 options · 39 votes" directly beneath at card-bottom-left.
      - Card-right: two buttons in a row — "Vote" (primary, filled) then "Results" (secondary, outlined) at card-middle-right.
    - Card 2 (second row): same structure — title "Which season do you like best?", meta "4 options · 39 votes", "Vote" + "Results" buttons at card-middle-right.
    - Card 3 (third row): same structure — title "Best way to start the morning?", meta "4 options · 40 votes", "Vote" + "Results" buttons at card-middle-right.
- Interactive elements: per card, "Vote" button (primary) and "Results" button (secondary), both at card-middle-right.

## Screen: poll-detail
- Header: top of viewport, centered — "Polls" wordmark at header-top-center, tagline "Cast your vote and see what others think" at header-bottom-center. Full-width horizontal divider beneath.
- Main content: a single bordered card centered horizontally below the header.
  - Card-top-left: back link "← Back to polls".
  - Below the back link, card-top-left: poll question heading "What is your favorite programming language?".
  - Card-middle: a vertical stack of four option rows, each a full-width bordered rectangle containing a radio button at row-left and the option label to its right:
    - First row: radio + "JavaScript".
    - Second row: radio + "Python".
    - Third row: radio + "Rust".
    - Fourth row: radio + "Go".
  - Card-bottom-left: two buttons in a row — "Submit Vote" (primary, filled) then "View Results" (secondary, outlined).
- Forms: radio-group (single-select among JavaScript / Python / Rust / Go) → submit button labeled "Submit Vote".
- Interactive elements: "← Back to polls" link at card-top-left; "Submit Vote" primary button and "View Results" secondary button at card-bottom-left.

## Screen: poll-results
- Header: top of viewport, centered — "Polls" wordmark at header-top-center, tagline "Cast your vote and see what others think" at header-bottom-center. Full-width horizontal divider beneath.
- Main content: a single bordered card centered horizontally below the header.
  - Card-top-left: back link "← Back to polls".
  - Below the back link, card-top-left: poll question heading "What is your favorite programming language?".
  - Directly beneath the heading, card-top-left: summary line "Total votes: 39".
  - Card-middle through card-bottom: a vertical stack of four result rows, each row consisting of:
    - A label line where the option name sits at row-left and the count/percent sits at row-right.
    - A horizontal progress bar directly below that line, spanning the full row width, filled from the left in proportion to the percentage.
  - Result rows in order:
    - First row: "JavaScript" (row-left), "12 · 31%" (row-right), bar filled ~31%.
    - Second row: "Python" (row-left), "15 · 38%" (row-right), bar filled ~38%.
    - Third row: "Rust" (row-left), "7 · 18%" (row-right), bar filled ~18%.
    - Fourth row: "Go" (row-left), "5 · 13%" (row-right), bar filled ~13%.
- Interactive elements: "← Back to polls" link at card-top-left.
