# Layout spec

Global shell (visible on every screen):
- Header (top of viewport): wordmark "Sable & Brown Detective Agency" at header-left (top-left of page), tagline "Discreet inquiries. Documented evidence. Trusted counsel." directly below the wordmark, also header-left. A horizontal rule spans the full width below the tagline.
- Primary nav (just below the header rule, top-left aligned, single horizontal row): five button-styled links in order — `Cases`, `Real-time Reports`, `Work Hours`, `Estimated Expense Sheet`, `Service Assignment Sheet`. The active item is rendered as a filled primary button; the others as outlined secondary buttons.
- Main content: a single full-width bordered panel below the nav, occupying the page-center.
- Footer (bottom-center of viewport): single line of fine print "Case file data is stored locally in your browser."

## Screen: cases
- Header / nav: as global shell; `Cases` is the active nav item.
- Main content (page-center, bordered panel): heading "Case Files" at panel-top-left.
- Two-column layout fills the panel below the heading:
  - Left column (middle-left of panel): vertical list of case cards. Each card shows, in top-left of the card: case ID (e.g. `C-1001`), then case title (e.g. "Missing Heirloom Brooch") on the next line, then client name below it. At card-top-right of each card: a pill-shaped status badge (`Active` or `Closed`). The currently selected card (first one, "C-1001 — Missing Heirloom Brooch") is highlighted with a filled dark background. Visible cards in order: C-1001 Missing Heirloom Brooch / Eleanor Whitcombe / Active; C-1002 Suspected Corporate Espionage / Brightline Robotics / Active; C-1003 Background Verification / Hollings & Partners / Closed.
  - Right column (middle-right of panel): a detail card for the selected case. Card-top-left: case title "Missing Heirloom Brooch". Below the title, a key/value list aligned in two columns (label at left, value at right of each row): `Case ID` C-1001, `Client` Eleanor Whitcombe, `Status` Active, `Priority` High, `Opened` 2026-04-12. Below the list, a sub-heading "Summary" at card-middle-left, followed by a single paragraph: "Antique brooch vanished from a locked drawing room during a dinner party."
