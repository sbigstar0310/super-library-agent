# Layout spec

Shared structure (visible on every screen):
- Header (top of viewport, full-width card): wordmark "Supply Chain Traceability" at header-left (large), with the subtitle "Track, verify, and analyze products throughout the supply chain." directly below it at header-left.
- Nav row (just below header, header-left aligned): a single horizontal row of five buttons in this order — `Register`, `Track`, `Inquiry`, `Verify`, `Statistics`. The button matching the current screen is shown in a darker/active style; the others are shown in a lighter/secondary style.
- Footer text (bottom-center, below the main content card): "2 product(s) on chain".

## Screen: register
- Header: as shared. Active nav button: `Register` (top-left of nav row).
- Main content: a single full-width card centered horizontally below the nav.
  - Card-top-left: title "Register a New Product".
  - Below title: helper text "Submit product details to mint a unique traceability ID and authentication code."
  - Form area (card-middle), arranged in a 2-column grid:
    - Row 1: `Product Name` → text input (left column); `Category` → dropdown select defaulted to "Food" (right column).
    - Row 2: `Origin` → text input (left column); `Manufacturer` → text input (right column).
    - Row 3: `Manufacture Date` → date input (spans full width), prefilled "05/22/2026".
  - Card-bottom-left: primary CTA button `Register Product`.
- Footer text visible below the card.
