# Layout spec

## Screen: login
- Header (top of viewport, full width, dark cyan band): wordmark "Insurance Automation System" at header-left; at header-right the text "Welcome, admin" followed by a "Logout" button.
- Nav bar (directly under header, full width, white): horizontal tab row at nav-left with labels in order: "Customers", "Policies", "Claims", "Reports". "Customers" is the active tab (dark cyan label with underline indicator).
- Main content: a single card region occupying the upper-center of the viewport, with wide horizontal margins.
  - Card-top-left: heading "Customer Management" (dark cyan).
  - Card-top-right: single-line "Search customers..." text input.
  - Row below the heading (card, spanning full width): four text inputs in a row from left to right — "Name", "Email", "Phone", "Address" — followed at the far right by an "Add" button (dark cyan, filled).
  - Table (fills remainder of card): header row (dark cyan background, white bold text) with columns "Name", "Email", "Phone", "Address", "Actions". Data rows below on white background:
    - Row 1: "Alice Johnson" | "alice@example.com" | "555-1001" | "12 Oak St" | Actions: "Edit" (outlined dark cyan), "Delete" (filled red).
    - Row 2: "Bob Smith" | "bob@example.com" | "555-1002" | "34 Pine Rd" | same Edit/Delete pair.
    - Row 3: "Carol Diaz" | "carol@example.com" | "555-1003" | "56 Maple Ave" | same Edit/Delete pair.
- Forms (inline, above table): Name → text → same-row inputs → "Add" submit button at row-right.
- Interactive elements: nav tabs (top), "Logout" (header-right), search input (card-top-right), "Add" (form-right), "Edit"/"Delete" per row (row-right).

## Screen: claims
- Header (top of viewport, dark cyan band): "Insurance Automation System" at header-left; "Welcome, admin" text and "Logout" button at header-right.
- Nav bar (below header): tabs at nav-left "Customers", "Policies", "Claims", "Reports". "Claims" is active (dark cyan with underline).
- Main content: single card centered horizontally in the upper portion of the viewport.
  - Card-top-left: heading "Claims Management" (dark cyan).
  - Card-top-right: an "All" dropdown (status filter).
  - Add-form row spanning card width, left to right: "Select Policy" dropdown, "Amount" text input, "Pending" status dropdown, date picker (mm/dd/yyyy), "Description" text input, then "Add" button (dark cyan) at row-right.
  - Table (full card width) with dark cyan header row and white bold labels: "Policy", "Amount", "Status", "Date", "Description", "Actions". Two data rows:
    - "Auto - Alice Johnson" | "$3,500" | "Approved" | "2025-06-01" | "Fender bender" | Actions at row-right: "Edit" (outlined dark cyan), "Delete" (filled red).
    - "Home - Bob Smith" | "$12,000" | "Pending" | "2026-01-20" | "Roof damage" | Actions at row-right: "Approve" (filled dark cyan), "Reject" (filled red), "Edit" (outlined), "Delete" (filled red).

- Interactive elements: nav tabs, "Logout", filter dropdown (card-top-right), form controls, "Add", per-row action buttons (Edit/Delete always present; Approve/Reject present only on Pending row).

## Screen: reports
- Header (top of viewport, dark cyan band): "Insurance Automation System" at header-left; "Welcome, admin" and "Logout" button at header-right.
- Nav bar (below header): tabs at nav-left "Customers", "Policies", "Claims", "Reports". "Reports" is active (dark cyan with underline).
- Main content: full-width area on whitesmoke background, no outer wrapper card.
  - Page title "Data Analysis & Reports" at page-top-left (dark cyan).
  - KPI row (directly under title, spans full width): six equal-width stat cards in a single row, each with small label at card-top-left and large value below (dark cyan). Left-to-right: "Customers 3", "Policies 3", "Claims 2", "Total Premium $2,700", "Total Coverage $275,000", "Claims Paid $3,500". Each card has a dark cyan left border accent.
  - Chart/summary row (below KPIs): three equal-width cards in a single row.
    - First card (row-left) "Policies by Type": rows of label + horizontal dark cyan bar with count inside. From top: "Auto" bar value 1, "Home" bar value 1, "Life" bar value 1.
    - Second card (row-center) "Claims by Status": rows label + horizontal bar. "Pending" 1, "Approved" 1, "Rejected" 0 (short bar).
    - Third card (row-right) "Policy Status Overview": small table with header row "Status" | "Count" (dark cyan bold) and rows "Active 2", "Pending 1", "Expired 0".
  - Bottom row: single card at row-left (about one-third viewport width) titled "Financial Summary" (dark cyan). Two-column list, label at row-left and value at row-right:
    - "Total Premium Revenue" — "$2,700"
    - "Total Coverage Value" — "$275,000"
    - "Total Claims Filed" — "$15,500"
    - "Approved Payouts" — "$3,500"
    - "Net Position" — "$-800"
- Interactive elements: nav tabs (top), "Logout" (header-right). No form inputs on this screen.
