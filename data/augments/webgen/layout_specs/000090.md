# Layout spec

## Screen: auth-login
- Header: none. Background fills the entire viewport.
- Main content: a single bordered card at viewport-center.
  - Card-top-center: wordmark "SocialCove".
  - Directly below wordmark (card-top-center): tagline text "Share moments. Earn points. Grow your circle."
  - Card-middle-top: a horizontal two-segment tab switcher spanning the card's width. Left segment "Log In" (filled/active), right segment "Register" (outlined/inactive).
- Forms: login form occupies card-middle to card-bottom.
  - Label "Username" (card-left, above input) → single-line text input (full card width).
  - Label "Password" (card-left, below the username input) → single-line text input (full card width).
  - Submit button "Log In" (filled, full card width) at card-bottom.
- Interactive elements:
  - Tab "Log In" (active) at middle-left of the tab row.
  - Tab "Register" at middle-right of the tab row.
  - Primary CTA button "Log In" at card-bottom-center, spanning full card width.

## Screen: auth-register
- Header: none. Background fills the entire viewport.
- Main content: a single bordered card at viewport-center.
  - Card-top-center: wordmark "SocialCove".
  - Below wordmark (card-top-center): tagline "Share moments. Earn points. Grow your circle."
  - Below tagline (card-top): horizontal two-segment tab switcher spanning full card width. Left segment "Log In" (outlined/inactive), right segment "Register" (filled/active).
- Forms: register form, card-middle to card-bottom.
  - Label "Username" (card-left) → single-line text input (full card width).
  - Label "Password" (card-left, below username) → single-line text input (full card width).
  - Label "Invite Code (optional)" (card-left, below password) → single-line text input with placeholder "e.g. AB12CD" (full card width).
  - Submit button "Create Account" (filled, full card width) at card-bottom.
- Interactive elements:
  - Tab "Log In" at top-left of tab row.
  - Tab "Register" (active) at top-right of tab row.
  - Primary CTA button "Create Account" at card-bottom-center.

## Screen: feed
- Header: top of viewport, full width, filled bar.
  - Header-left: wordmark "SocialCove".
  - Header-center: three navigation buttons in a row — "Feed" (active), "Friends", "Profile".
  - Header-right: pill badge "25 pts", then username text "@alice", then outlined button "Log out" (in that left-to-right order within header-right).
- Main content: a single centered column below the header, occupying top-center of the viewport below the header.
  - Top card (page-top-center): titled "Share a Picture" at card-top-left.
    - Card-middle-top: file input row with "Choose File" button at row-left and helper text "No file chosen" to its right, inside a dashed-bordered row spanning card width.
    - Card-middle: multi-line text area with placeholder "Say something about it...", spanning full card width.
    - Card-bottom-left: filled primary button "Post (+5 points)".
  - Below the top card: section heading "Updates" aligned with the left edge of the column.
  - Below the "Updates" heading: a dashed-bordered panel spanning the column width.
    - Empty state text "No posts yet. Be the first to share!" at panel-center.
